## 笑いのルール

【用語】
・拍＝ビート1つ。小節＝4拍。BPM＝1分間の拍の数。
・LU＝音の大きさの単位。
・数字は試作のテンポ（112.5 BPM）で書きます。1拍＝0.533秒、1小節＝2.133秒です。

【ルール1：笑いの基本形】
期待させる → 裏切る → 前より大きく直す。
・直したあとは、必ず前より豪華にします（全部の楽器が戻る、和音を足す、カメラが引く）。
・音を大きくして豪華にするのではなく、楽器の数で豪華にします。

【ルール2：3回の法則】
1回目で見せる、2回目で確かめる、3回目で外します。
・試作では、LEVEL 0（手で1拍）で見せる → LEVEL 8（同じポチャン。ただ受け皿のふちで1回跳ねてドキッ）で確かめる → LEVEL 64（64音目が鳴らない）で外す。
・4回目まで引っぱりません。

【ルール3：「間（ま）」の決め方】
間＝「次の出来事が起きない時間」です。2種類あります。
・A 動きの間：音楽は続けて、キャラと機械だけが止まる（Mr. Bean の型）。
・B 音の間：メロディとドラムが止まる。メトロノームのチックと小さな和音（パッド）だけ残す。
長さ（社内の目安）：
・Shorts：どちらも1回0.5〜1.5秒。完全な無音（チックも止まる）は使わない。
・長尺：A は最大4拍（約2.1秒）、B は最大1小節（約2.1秒）。完全な無音は1本に1回、1秒以内。
・0.5秒より短くしない理由：文字のジョークを1語ずつ読ませた研究で、最後の言葉のあと約0.5〜0.9秒で脳の反応が出たものがあります（Coulson & Kutas 2001）。映像にそのまま当てはまるかは分かりません。0.5秒は社内の目安です。

【ルール4：試作の笑いの時刻表（この数字で作ります）】
・笑い1（小）0.533秒 手でポチャン → 動きの間 1.067秒
・笑い2（小）4.400秒 受け皿のふちで「コッ」→ 4.533秒 ポチャン → 動きの間 1.067秒
・笑い3（大）18.400秒 64音目が鳴らない → 音の間 0.8秒 → 19.200秒と20.267秒に押す → 21.333秒（小節の頭）に解決
・笑い4（締め）24.267秒 カードが勝手に「LEVEL 512」へ → 24.800秒 帽子のつばだけ向く → 25.600秒 何もなかったように「LEVEL 0」に戻す
・どの間も0.5〜1.5秒の中です。

【ルール5：笑いの数と間隔】
・Shorts：1本に3〜4回（小さな笑いも数える）。最初の笑いは1秒以内。メインの笑いは7秒より後。
・長尺：小さな笑いは30〜45秒に1回。中くらいは1.5〜3分に1回。伏線は2本（帽子とメトロノーム）、それぞれ3回出して最後に回収。
・笑いが画面に出ている時間：Shorts は全体の3分の1まで。長尺は15〜25%（推定）。主役は気持ちよさです。

【ルール6：次の出来事は1秒あける】
オチのあと、次の新しい出来事（カードがめくれる等）は1秒以上あとに置きます。笑う時間を残すためです。

【ルール7：主役は驚かない（シュールの決まり）】
・何が起きても、FELT は大きく反応しません。
・反応は1本に1回まで。0.5〜1拍おくれて、帽子のつばを向けるだけ。
・締めは「何もなかったように戻る」。

【ルール8：音でオチをつける】
・オチの音は、画面の中の楽器の音だけ（ガラス・鐘・木・陶器）。漫画の効果音（ボヨン、ピュー）は使いません。
・外れた音＝半音ずらした音（ピアノの隣の鍵盤）。
・途中のポチャンは小さな単音。最後のポチャンだけ、曲の中心の音（主音。試作ではレ＝D）に和音と全部の楽器を重ねます。
・オチの音は、直前10秒の真ん中の音量より +10 LU 以内。大きな山は、だんだん大きくなる音（ライザー）で予告します。
・飲む場面に、すする音・口の音は入れません。

【ルール9：ニアミス（あと少しで失敗）は1本に1回】
・危ないのは機械とメロディだけ。キャラの命ではありません。
・危機は2〜4秒前から画面に見せます（試作では15.9〜16.6秒に、列の先の古いドミノを映す）。
・助かる瞬間は、次の小節の1拍目ぴったり。

【ルール10：誰も傷つかない】
・的は、機械・計画・プライド（帽子）・顔のない物だけ。
・玉や部品を棒人間に当てません。
・使ってよい：水がはねる、紙吹雪、帽子が飛ぶ。
・使わない：赤いペンキ（血に見える）、煤で顔が黒くなる（人種の戯画に見える）、転ぶ・落ちる、火、屋根から飛ぶ。
・高い所を通るのは物だけ。人は登りません。
・鉄球は机の上のレールだけで転がします。人に向けて投げません。

【ルール11：本物の物理】
・落ちる高さ・飛ぶ弧は、音符の時刻から計算します（本物の重力 9.81m/s²）。
・ドミノの倒れる速さは、実物に近い値にします（試作は秒速約1.3m、推定。数値で確かめる）。
・「力ではなくタイミング」は、揺れ続けている物を、揺れに合わせて押す「共振」で見せます。止まっている物を軽く押して倒す、はしません（物理のうそになるため）。
・倒れない理由（底が丸くて重い）は、0.5秒だけはっきり見せます。

【ルール12：文化の落とし穴】
・手のサイン（親指を立てる、OKサイン、指さし）は使いません。
・お酒・豚・牛のネタは使いません。
・レベルの数字とサムネで、「4」だけ・「13」だけを大きく見せません。カウンターが通りすぎるのはかまいません。
・言葉遊びや字幕のギャグは使いません。画面の文字は、数字と LEVEL だけです。

【ルール13：結末の型は順番に回す】
5つの結末の型を順番に使います。直前2本と同じ結末にはしません。

## おすすめの企画

【名前】
THE LONG WAY（遠回りレベル）※仮の名前。商標とYouTubeの @名前は未確認です。

【ひとことで】
手なら1拍で終わる用事を、机の上の「演奏する装置」でわざわざやります。
レベルが上がるほど、装置も曲も長くなります。
なのに、ゴールの用事は小さいままです。

【レベルの決まり】
・レベルの数字＝装置が鳴らす音の数。約束はこれだけです。
・0 → 8 → 64（長尺の最後だけ512）。
・机の上のめくり式カウンターが、鳴った音の数を数えます。カードの数字に届いたら、ゴールの合図です。
・長さの目安（112.5 BPM）：LEVEL 8 は約2秒、LEVEL 64 は約13秒。
・LEVEL 512 は、100 BPM で8分音符256個＋16分音符256個にすると約1分55秒です（16分音符だけなら約77秒、8分音符だけなら約2分34秒）。

【キャラ】
・主人公：顔のない棒人間（仮の呼び名 FELT＝フェルト）。
　- つや消しの白い陶器のような体。深緑のフェルトの、つばのある帽子。
　- 夕方、机でひと息つきたいだけの大人です。いつも真顔です。
　- 気持ちを見せる演技は2つだけ：「止まる」と「見る」。
　- 「見る」は帽子のつばの向きで見せます。顔がなくても、どこを見ているか分かります。
　- 作業の動きは別に5つ：つまんで落とす、レバーを押す、カップを持ち上げて置く、ボタンを押す、角砂糖をつまむ。
　- いまの棒人間の骨組みは、腕が前後と上下にしか動きません。なので、手で触る物は全部、右手の前の一列に並べます。
・相棒：机の上のメトロノーム（付喪神＝魂の宿った道具。顔なし）。
　- 0秒からずっと拍を刻みます。
　- 装置がつまったとき、振り子で、揺れに合わせて押して助けます。
・舞台：夕方の木の机。真ちゅう・ガラス・陶器。落ち着いた映画のような光。
・3Dならではの見せ場：レベルが上がるたびにカメラが引き、机 → 部屋 → 家の模型へ広がります。

【つかみ（最初の2秒）】
・0秒：カップの上で角砂糖をつまんだ手。カードは「LEVEL 0」。メトロノームのチック。
・0.533秒：手を離して「ポチャン」。1拍で用事が終わる（最初の小さな笑い）。
・0.533〜1.6秒：真顔。帽子のつばだけがカメラを向く。
・1.6秒：カードが「LEVEL 8」にパタン。「え、まだやるの？」

【角砂糖が何個も入らないように】
・カップは毎回、新しいものに入れかわります（机の上の小さなレールで、横に1つずれる）。
・最後に上から見ると、札「0」「8」「64」の付いた同じ3つのカップが並んでいます。「結果は全部同じ」が一目で分かります（並べて比べる見せ場）。

【笑いの仕組み（Shorts 1本目）】
1. LEVEL 0 は手で1拍。最初の期待はずれ。
2. LEVEL 8 も結果は同じポチャン。ただ、受け皿のふちで1回「コッ」と跳ねて、ドキッとさせる。
3. LEVEL 64 では、最後の1音（64音目）だけ鳴らない。
　- カウンターは「063」で止まったまま。
　- 列の最後の古い木のドミノ（底が丸くて重い）が、ぐらぐら揺れるだけで倒れない。
　- 横のメトロノームの振り子が、揺れが戻ってきた瞬間に2回、拍ちょうどでちょんと押す。押すたびに揺れが大きくなり、倒れる（共振）。
　- ふつうのドミノが当たっても倒れなかったのに、揺れに合わせた小さな一押しで倒れた＝力ではなくタイミング。
4. 64音目が鳴り、次の小節の頭でポチャン。全部の楽器が戻る。
5. 一口飲んでいると、カードが勝手に「LEVEL 512」にめくれる。FELT は真顔のまま「LEVEL 0」に戻し、次の角砂糖をつまむ（何もなかったように戻る）。

【回ごとに変える骨組み（3種類以上を順番に）】
・A 上り階段：0 → 8 → 64
・B 下り階段：64 → 8 → 0（最後の「手で1拍」が、全部の楽器と一緒の一番の山になる）
・C 2台の競争：LEVEL 8 と LEVEL 64 が同時に動き、同じ拍でゴールする
・D 1台だけ：LEVEL 64 一発。途中の笑いが主役
・E 途中で終わる：LEVEL 8 で用事が済んでしまい、LEVEL 64 の出番がない

【途中の笑いの型（回ごとに1つ）】
・最後の1音が出ない → 共振で助ける
・1音だけ半音外れる → 装置が1拍止まる → 直して、前より豪華に弾き直す
・部品が1つだけ合わない（Honda Kog の型）
・ぷるんと揺れる部品が、3回はねてからやっと止まる

【結末の型（5つを順番に）】
①ちゃんと成功＋最後に小さなオチ
②待ちきれず、装置が終わる前に手でやってしまう
③装置が別の用事をしてしまう（ランプのつもりが扇風機。帽子が飛ぶ）
④最後の1段だけ、結局手で押す
⑤装置が隣の物（隣のカップ、隣の植木）に届けてしまう

【気持ちよさの仕組み】
・装置が当たるたびに、それが1つの音符になります。
・玉の飛び方は、前と次の音の時刻から逆算します（本物の重力）。
・音の鳴るドミノの波、6段の木琴の塔を下りる玉、ちょうど8分音符ぶん落ちるおもりとシーソー。
・カウンターがパラパラと進みます。
・2〜5秒ごとに、見せる部品が変わります。
・毎回1つ、見た目の見せ場を入れます。例：角砂糖がほどける白い渦を真上から／上から見るとS字のドミノ／装置の全景を上から／長尺では家の模型まで引く。
・最後の用事は、小節の1拍目にぴったり決まります。

【音の役割】
・装置の長さ＝曲の長さ。LEVEL 8 は短いフレーズ、LEVEL 64 は約6小節、LEVEL 512 は1曲まるごと。
・メトロノーム＝クリック（曲の拍の基準）。最初の1秒から鳴らします。曲のない時間を作りません。
・曲は玉で始まります。LEVEL 8 でビー玉が最初の皿を鳴らした瞬間にキックとベースが入り、LEVEL 64 で鉄球が銅鑼を鳴らすと全部の楽器が入ります。
・途中のポチャンは小さな単音。最後のポチャンだけ、曲の中心の音に和音と全部の楽器を重ねます。
・ニアミスでは、ドラムとメロディを抜いて、ベースとメトロノームだけにします。
・曲はオリジナル。ジャズ・ファンク寄りで、童謡っぽくしません。
・音のロゴは、オーナーの鼻歌から作る4音です（毎回入れます）。

【長尺：THE LONG WAY: One Evening, Four Chores（約9分35秒）】
長さは中身で決めます。8分に合わせて引き伸ばしません。
横長で新しく描き直し、Shortsにない部品・つなぎの物語・新しい編曲を足します。用事は4つです。
・0:00〜0:25 帰宅。FELT が帽子を壁のフックへ投げて、外れて机に落ちる（帽子の伏線1）。メトロノームを動かす（拍が始まる）。
・0:25〜1:55 用事1「ランプをつける」（100 BPM、ヘ長調、骨組みE）。LEVEL 0 → 8。LEVEL 8 がランプではなく扇風機をつけ、帽子が机から飛ぶ（帽子の伏線2）。FELT は手でランプをつける（真顔）。LEVEL 64 の装置は出番がないまま。
・1:55〜3:55 用事2「紅茶に角砂糖」（112.5 BPM、ニ長調、骨組みA）。Shorts 1本目の長い版に、新しい部品を2つ足す（例：ぷるんと揺れるゼリーの板、ビー玉16個のなだれ）。共振のニアミス。
・3:55〜4:15 つなぎ：部品が1つ足りない → メトロノームの振り子を外して部品にする → 拍が消える → FELT が指でトントンと拍を取る（メトロノームの伏線）。
・4:15〜6:05 用事3「植木に水」（90 BPM、変ロ長調、はねるリズム、骨組みD）。玉が隣の板に当たって半音低い音 → アームが1拍止まる → 小さなレンチで直す → 全音上に転調して弾き直す。最後の1段だけ手で押す（結末④）。
・6:05〜6:25 つなぎ：カメラが引くと、家全体の模型（断面）が見える。
・6:25〜8:45 フィナーレ用事4「帽子をかける」LEVEL 512（100 BPM）。準備20秒＋装置が動く約1分55秒＋着地5秒。机 → 床 → 本棚 → 窓辺 → 家の模型の屋根（通るのは物だけ）→ ドアの横のフック。今までの3曲のモチーフを全部重ねた新しい編曲。512音目と同時に帽子がフックにかかる（帽子の伏線3）。最後に「LEVEL 0：1拍（0.6秒）」と「LEVEL 512：約1分55秒」の画を横に並べて1.5秒。
・8:45〜9:15 締め：FELT が帽子を取って出かけようとすると、ドアの横の手の届く所に、もう1つフックがある（真顔4拍）。メトロノームを止める。最後の「チン」。
・9:15〜9:35 終了画面用（メトロノームの音だけ）。
・笑いの量：小さな笑い約30〜45秒に1回、中くらい約2分に1回、伏線2本。笑いの画面は約20%（推定）。

【Shorts（20〜35秒）の基本の流れ（骨組みAの場合）】
・0〜0.6秒：LEVEL 0（手で1拍）。最初の音は0秒のメトロノーム。
・0.6〜1.6秒：真顔。
・1.6〜2.1秒：カードが LEVEL 8 に。カップが入れかわる。
・2.1秒：ビー玉が最初の皿を鳴らして、曲が始まる。3秒以内に「同じ用事を、だんだん大げさにする」が分かる。
・2.1〜5.6秒：LEVEL 8 と、ぶつかる場面なしの小さな笑い。
・5.6〜7.5秒：LEVEL 64 の予告（ライザー）。7.0秒より後に、一番強い当たり（銅鑼）。
・8〜21秒：連鎖。メインの笑いは18〜21秒。
・21〜27.7秒：解決 → 上から全景 → 締めのオチ → 最初の画にもどる。
・回ごとに、用事・骨組み・新しい部品1つ以上・結末の型・曲（キー・テンポ・コード進行のうち2つ以上）を変えます。

## ほかの案

3人の審査の平均点の順です。

【1. TAP — Timing Beats Strength（平均7.3点、審査2の1位）】
・巨大な振り子の鐘を、力ずくでは動かせない。拍に合わせて小さく押すと揺れが育つ、という話です。
・良い所：回ごとに本物の物理現象を変えられる。子ども向けに見られにくい。描くのが軽い。
・今回選ばない理由：Shortsの最初の約8秒が曲なしの失敗で、スワイプ（指で次の動画へ飛ばすこと）されやすい。玉やピタゴラの連鎖がほぼない。棒人間の演技に頼る。
・使い道：「揺れに合わせて押すと倒れる（共振）」を、THE LONG WAY の64音目の場面に入れました。あとで、メトロノームが主役の別シリーズにもできます。

【2. LATE BALL＋ODD MARBLE OUT（平均6.8点／6.3点、審査3の2位）】
・いつも遅れる、または音を外す銅の玉が出てくる、ビー玉の演奏機械です。
・良い所：棒人間の演技がいらない。今のコードで作りやすい。
・今回選ばない理由：毎回「同じ玉が同じ状況」になりやすく、YouTubeが2026年7月に例に挙げた型に近い。「半拍おくれ」は、音を消したスマホでは伝わりにくい。
・使い道：オーナーが「棒人間なし」を選ぶなら、こちらにします。「1音だけ外れる→直して前より豪華に」は、THE LONG WAY の途中の笑いに入れました。

【3. THE DOMINO THAT WOULDN'T（平均6.8点、審査1の1位）】
・1枚だけ倒れないドミノの話です。
・今回選ばない理由：重さの階段（1g→1000kg）が Kawaken に近い。「重い物が当たっても倒れないのに、しずくで倒れる」が物理のうそに見えやすい。
・使い道：64音目の「古い木のドミノ（底が丸くて重い）」として入れました。ただし倒し方は、うそにならない「共振」に直しました。

【4. IT SHOULDN'T WORK（平均6.8点）】
・四角い車輪など、本物の数学でありえないことを成功させる案です。
・今回選ばない理由：笑いが弱い。ネタの数に限りがある（20〜30と推定）。
・使い道：特別回の候補。

【5. TUNING DAY＋THE TUNER（平均6.3点）】
・真顔の調律係が、音の外れる巨大マシンを直す案です。
・今回選ばない理由：手で物を扱う演技が多く、今の骨組み（腕が前後と上下にしか動かない）では重い。
・使い道：帽子のつばで向きを見せる工夫を、THE LONG WAY に入れました。骨組みを直したあとの別シリーズ候補です。

【おすすめしない案】
・ONE PART HAS OTHER PLANS（6.0点）：著作権の切れた曲でも、YouTubeの自動照合で誤った申し立てが来やすい。
・THE LAST DOMINO（5.8点）：ドミノが自分で跳ねるのは、物理の気持ちよさと逆。良いネタは THE LONG WAY に回します。
・TICK（5.7点）：「毎朝同じ人を起こす」が同じ状況のくり返しに近い。作る物が一番多い。
・TENFOLD（5.2点）：Kawaken に一番似ていて、破片の描画が重い。

## 機械演奏案・比較ジャンルとの組み合わせ

【「機械が演奏する音楽」の案と】
・1台の装置＝1曲です。レベル＝装置が鳴らす音の数（8→64→512）。カウンターは「何音鳴ったか」を数えます。
・曲が先で、玉の飛び方を音符の時刻から逆算します（pitch試作と同じ方式）。
・だから、実物のピタゴラ装置ではできない「全部が拍にぴったり」が見どころになります。
・Animusic や Wintergatan には笑いがありません。そこに笑いを足すのが新しさです。
・音のロゴは、オーナーの鼻歌から作る4音です。

【比較ジャンル（Kawaken、RED SIDE）の発見と】
・正直な違い：Kawaken の気持ちよさは「崩れる見た目」、うちは「音に合う連鎖」です。同じ土俵では勝ちにくいので、毎回1つ、うちでも描ける見た目の見せ場（渦、S字のドミノ、上からの全景）を足して近づけます。
・Kawaken の「1段目はわざと期待はずれ → だんだん大きく」を使います。
　→ LEVEL 0（手で1拍）→ 8 → 64。
　軸は重さではなく「音の数」なので、まねにはならないと考えます。公開前に、似た動画を検索して見比べます。
・Kawaken の「約5秒ごとに条件が変わる」テンポ → うちは部品を2〜5秒ごとに変えます。
・Kawaken の「週2本のShorts → 約8分の長尺まとめ」の出し方を参考にします。
　ただし、うちのルールでは自分のShortsを並べただけの長尺は作りません。長尺は横長で描き直し、新しい部品・つなぎの物語・新しい編曲を足します。長さは中身で決めます（約9分35秒の案）。
・RED SIDE の「並べて比べる」→ 試作の最後に「同じ3つのカップ」、長尺の最後に「LEVEL 0：1拍」と「LEVEL 512：約1分55秒」を横に並べます。爆発はしません。
・C4D4U の「ゆっくり待たせて、ぴったりはまる」と「場面ごとのオチ」→ ニアミスと締めのオチに使います。C4D4U がやっていない「オチと音を合わせる」が、うちの差です。
・並行で進んでいる比較ジャンルの分析で強い型が見つかったら、この「並べる場面」と「レベルの段」に取りこみます。

【オーナーの好みと】
・玉で曲が始まる音ハメ：LEVEL 8 でビー玉が最初の皿を鳴らすとキックとベースが入り（2.1秒）、LEVEL 64 で鉄球が銅鑼を鳴らすと全部の楽器が入ります（7.5秒）。
　投げた玉ではなく、転がした玉です。投げる形に寄せたいなら、長尺の冒頭で FELT が帽子を投げる場面を、玉を投げる形に変えることもできます。
・ピタゴラ・ドミノの連鎖：装置そのものが連鎖です。音の鳴るドミノも使います。
・Alan Becker 系の棒人間：真顔の間とタイミングで笑わせます。色分け棒人間やパソコン画面の見た目はまねしません。
・糸人間作品系の3D棒人間：顔なし、陶器の質感、帽子。
・付喪神（魂の宿った道具）：メトロノームが、顔なしで動きだけで性格を出す相棒です。
・長尺とShortsの両方：Shortsで人を集め、長尺で長く見てもらう形です。
・笑いの種類「シュール」：主役は驚かない、締めは何もなかったように戻る、を決まりにしました。

【ほかの案から入れた部品】
・倒れないドミノ → 64音目の古い木のドミノ。倒れない理由を0.5秒見せる。
・TAP → 揺れに合わせて押すと揺れが育つ（共振）。力ではなくタイミング。
・LATE BALL／ODD MARBLE OUT → 「1音だけ外れる → 装置が1拍止まる → 直して前より豪華に」を、別の回の途中の笑いに。
・THE TUNER → 帽子のつばで向きを見せる。帽子の伏線。
・Honda Kog → 「1つだけ合わない」部品の回。

## 作り方

【1本の作り方の流れ】
1. 企画シートを書く（一言の筋、用事、骨組み、新しい部品、結末の型、曲、視聴者層とその理由）。
2. 曲を作る（キー・テンポ・コード・メロディ）。モチーフはオーナーの鼻歌から。
3. 楽譜にギャグも書く（種類・何拍目か・間の長さ・どう直すか）。
4. 楽譜から装置の部品を並べる。
5. 540x960 で下見して直す。
6. 1080x1920 で本番を描く。
7. 音量を -14 LUFS、トゥルーピーク -1.5 dBTP にそろえる（今の仕組みで実装済み）。
8. 自動チェックと人のチェック（公開前チェックリスト、2分の価値テスト7問）。
9. 投稿。

【最初に作るもの】
① 試作（オーナーの「作ってよい」のあと）：6〜9日（推定）。簡易版なら3〜4日（推定）。中身は prototype の項目のとおり。
② 試作のコードを本番用に移す（tools/nonverbal/ へ。試作のままでは使いません）。
③ 楽譜から装置の部品を自動で並べる道具（3〜5日、推定）。LEVEL 64 や 512 を手で並べると作業が回らないためです。
④ 部品の棚：銅鑼、金属の皿、木琴のレール、木琴の塔、シーソー、スプーンの投石機、ドミノ、揺れる古いドミノ、メトロノーム、カウンター、カップのレール。
⑤ 出来事の記録（まだ無い仕組み）とギャグの記録。これで自動チェック（冒頭、音量、急な音、ループ、音ズレ）を動かします。
⑥ 企画シートの形式。
・②〜⑥の準備で合計6〜10日（推定）。

【1本あたりの日数（推定）】
・Shorts：最初の1本まで約2週間。2本目からは2〜3日。ただしこれは、③の「部品を並べる道具」ができてからの数字です。
・長尺（約9分35秒）：15〜25日。

【描画時間（推定）】
・根拠：pitch試作は 540x960 で743コマを約100秒（1コマ約0.135秒）。otohame試作は 1080p60 で1秒に約1.06コマ。SDF（形を式で描く方法）を4spp（1コマを4回描いて平均し、なめらかにする設定）にすると1コマ約2.8秒。
・Shorts 27.7秒（1664コマ）：540x960 で約6〜14分。1080x1920 で約25〜55分。
・長尺（約3.4万コマ）：1回約8〜25時間（ひと晩〜2晩）。LEVEL 512 の場面は部品が多く、もっと遅くなるかもしれません。映っている部品だけを描く工夫が要ります（2〜3日、推定）。

【描くときの決まり】
・ガラスは「すりガラス」にします。本物の屈折は重いからです。
・ふだんは1spp、見せ場だけ4spp。
・直しは、区間だけ描き直す patch.py で行います。ただし今の patch.py は別の試作専用なので、読みこむ部分と画面の大きさを変える小さな手直しが要ります（半日、推定）。
・カットは小節の頭だけ。基本はなめらかな長回し。
・最初の1秒から拍（メトロノーム）が鳴っています。

【棒人間について】
・今の骨組み（rig.py）は、腕と脚が体の前後と上下にしか動きません。腕が横に開くのは、腕を高く上げたときだけです。首を回す関節も、肩をすくめる関節もありません。
・なので試作では、手で触る物を全部、右手の前の一列（体の中心から右へ約12cmの線上）に並べます。
・「見る」は、帽子のつばだけを回して見せます。骨組みそのものは直しません。
・あとで手を横に伸ばしたくなったら、腕を横に開く角度と、手先の位置から腕の角度を決める簡単な仕組みを足します（1〜2日、推定）。
・演技が伝わるかは、演技テスト（音なしの10秒を、初めて見る10人中8人がキャラの気持ちを言えたら合格）で確かめます。

【1週間の作業（推定。準備が終わったあと）】
・オーナー：鼻歌（10〜20分）、企画シートの承認、完成動画の確認、タイトルと概要欄の決定 → 週1〜2時間。
・Claude（オーナーが始めるセッション）：作曲・部品・調整。Shorts 1本で2〜3日分。長尺1本で15〜25日分。セッションを始めないと進みません。
・パソコンの描画：Shorts 1本で約1時間、長尺1本で1回8〜25時間（夜に回す）。
・Shorts 週2本（週4〜6日）と長尺を同時には回せません。なので、
　- 3か月目〜：Shorts 週1本（2〜3日）＋残りの日で長尺 → 長尺は約6〜10週に1本。
　- 部品の棚がそろって Shorts 1本が1.5日以下になったら、Shorts 週2本にします。

【オーナーにお願いすること】
・シリーズの音のロゴ（4音）の鼻歌。

## リスク

【1. オーナーが思う「気持ちいい3D」とずれる】
・Kawaken の気持ちよさは「崩れる・つぶれる見た目」、この案は「音に合う連鎖」です。
・対策：最初にオーナーに選んでいただく。毎回1つ、うちでも描ける見た目の見せ場を入れる。試作の合格チェックに「音を消して見ても気持ちいいか」を入れる。
・崩れる見た目を柱にするなら、その前に「破片をどこまで速く描けるか」の試験が要ります（うまくいくかは未確認）。

【2. ほかの作品に似すぎる】
・Joseph's Machines、NHKのピタゴラ装置、Honda Cog に似る心配があります。
・対策：夕方の机の世界、曲になる装置、メトロノーム・カウンター・帽子のお約束、3Dならではの大きさの段（机→部屋→家の模型）。「ピタゴラ」の名前は使いません。有名な連鎖は写しません。公開前に似た動画を検索して見比べます。

【3. 物理のうそに見える】
・揺れる古いドミノが2回の押しで倒れるか、ドミノの波の速さ（秒速約1.3m）、倒れるまでの0.533秒は、どれも推定です。
・対策：試作で数値計算をして確かめます。合わなければ、底の丸みとおもり、押す回数（3回にして1小節のばす）、テンポを変えます。

【4. 「CGなら何でもできる」で驚きが減る】
・対策：物理を本物どおりにし、倒れない理由を見せます。そのうえで、実物ではできない「全部が曲の音符にぴったり」で勝負します。

【5. 結果が分かっていて、最後まで見る理由が弱い】
・対策：カウンター（あと何音？）、ニアミス（063で止まる）、骨組み5種と結末の型5つを回します。

【6. 型どおりと判断される】
・YouTubeは2026年7月に「キャラを同じ状況に何度も置いて同じ結末にする動画」を例に挙げました。
・対策：用事・骨組み・新しい部品・結末・曲を毎回変えます。企画シートが4本以上たまってから投稿します。月1回、外部の人に直近3本の冒頭5秒とサムネを見てもらい、同じ1文で説明されたらその型を止めます。

【7. 子ども向けと判定される】
・ピタゴラ装置は、日本では子ども番組の代表です。判定されると広告単価が大きく下がります（第三者の数字で、長尺の真ん中の値約2.3ドル→子ども向け約0.33ドル）。
・対策：大人の机、真ちゅう・木・ガラス、夕方の光、ジャズ寄りの曲、目なし。おもちゃ（電車・お菓子）は使いません。1本ずつ判定して理由を書きます。

【8. 棒人間の演技が固い・手が届かない】
・今の骨組みは、腕が前後と上下にしか動きません。
・対策：気持ちを見せる演技は「止まる」「見る（帽子のつば）」の2つにしぼり、触る物は右手の前の一列に並べます。演技テストで先に確かめます。

【9. 作業が週に収まらない】
・Shorts 週2本と長尺を同時には回せません。
・対策：最初は Shorts 週1本＋長尺6〜10週に1本。部品の棚がそろってから週2本にします。

【10. 描画が重い】
・LEVEL 512（長尺）は部品が多いです。S字のドミノには新しい描き方が要ります（1〜2日、推定）。
・対策：映っている部品だけを描く工夫、1spp基本、見せ場だけ4spp、すりガラス。S字が間に合わなければ、まっすぐの列にします。

【11. 急な大きい音】
・曲が入る所（2.1秒）と、銅鑼の所（7.5秒）です。
・対策：冒頭から小さな和音（パッド）を鳴らしておく。銅鑼の前は、5.6秒からライザーと木のレールを転がる音で約1.9秒予告する。直前10秒の真ん中の音量＋10 LU 以内にし、書き出したら測ります。

【12. 名前のかぶり】
・「THE LONG WAY」はありふれた言葉で、検索で埋もれやすいです。「FELT」も同じです。商標と @名前は未確認です。
・最初の仮名「TINK」は、ディズニーのティンカー・ベルの呼び名と同じなのでやめました。

【13. 本業へのリスク】
・重い違反で、朗読チャンネルの収益化まで止まることがあります。最初の1年は保守的にします。

【14. 調査の限界】
・YouTubeを直接開けず、多くの再生数は未確認です。Kawaken と RED SIDE の1日の再生は、2か月前（7〜8月）の数字です。

■ オーナー向け（5行のまとめ）
━━━━━━━━━━━━━━
・題：THE LONG WAY 試作1「Level 0 vs Level 64 for One Sugar Cube」
・縦型、27.7秒。紅茶に角砂糖を1個入れるのに、手（LEVEL 0）→ 小さな装置（LEVEL 8）→ 机いっぱいの装置（LEVEL 64）。
・64音目だけ鳴らず、古いドミノが揺れるだけ。メトロノームが揺れに合わせて2回押すと倒れて、ポチャン＋全部の楽器。
・最後、カードが勝手に「LEVEL 512」になるのを、真顔で「LEVEL 0」に戻して終わる（最初にもどる）。
・作るのは、オーナーが「作ってよい」と言ってから。6〜9日（推定）。簡易版は3〜4日（推定）。

【絵コンテ（言葉で8コマ）】
1. 0秒：カップの上で角砂糖をつまむ手。カード「LEVEL 0」。チッ、チッとメトロノームの音。
2. 0.5秒：手で落として「ポチャン」。帽子のつばだけがこちらを向く（真顔）。
3. 1.6〜4.5秒：カードが「LEVEL 8」に。カップが新しいものに入れかわる。ビー玉が皿と木琴を鳴らし（ここで曲が始まる）、スプーンが角砂糖を飛ばす。受け皿のふちで「コッ」と跳ねて、ポチャン。
4. 5.6〜7.5秒：カード「LEVEL 64」。カメラが引くと、机いっぱいの装置。列の端に、1枚だけ黒っぽい古いドミノ。鉄球が転がって、7.5秒に銅鑼「ゴーン」で全部の楽器が入る。
5. 8〜18秒：皿 → 6段の木琴の塔 → シーソー → S字のドミノ。カウンターが 001→063 と進む。
6. 18.4秒：古いドミノだけ倒れない。ぐらぐら揺れて、ドラムが止まる。カウンターは「063」のまま。
7. 19.2秒・20.3秒：横のメトロノームの振り子が、揺れに合わせて2回ちょんと押す。揺れが大きくなってパタン。64音目が鳴り、21.3秒にポチャン＋全部の楽器。上から見ると、3つのカップは全部同じ。
8. 24〜27.7秒：一口飲んでいると、カードが勝手に「LEVEL 512」にめくれる。真顔のまま「LEVEL 0」に戻し、次の角砂糖をつまむ（最初の画にもどる）。

■ 作り手向け（ここから下は制作用の細かい数字です）
━━━━━━━━━━━━━━

【目的】
・オーナーが見て笑えるか、音を消して見ても気持ちいいかを確かめる。
・笑えなければ、同じ長さで LATE BALL（棒人間なし）の試作を作って比べる。

【形式】
・縦。まず 540x960、合格したら 1080x1920。60fps。

2. 冒頭：最初の音0.000秒。一番強い当たり（銅鑼7.467秒）は7秒より後。
3. 急な音：静かな所で、直前10秒の真ん中の音量より10 LU 以上跳ねない（予告付きは例外）。
4. 音量：-14 LUFS ±1、トゥルーピーク -1.5 dBTP 以下。
5. ループ：最後のコマと0コマ目の差を数字で測り、小さい。音も切れ目なくつながる。

7. 物理：上の計算どおり。古いドミノの揺れを数値計算で確認。ランダムな5コマで、めりこみや破綻がない。
8. 笑いのテスト：まずオーナーが見る。次に3〜5人（できれば日本語が分からない人を2人以上）に、音ありと音なしで見てもらう。聞くこと：どこで笑ったか、最後まで見たか、メトロノームが何をしたか。音なしでも「63で止まって、メトロノームが揺れに合わせて押して倒した」が半分以上の人に伝われば合格。

（おすすめ：出す）

・C：0 → 1 → 10 → 100（分かりやすいが、Kawaken の階段に近い）
（おすすめ：A）
