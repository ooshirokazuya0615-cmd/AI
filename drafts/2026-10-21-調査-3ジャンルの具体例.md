## ① 振付した言葉なしのキャラアクション（音楽に合わせて当たる）

**代表作：Alan Becker「Note Block Battle」**
https://www.youtube.com/watch?v=c0egcErkap0
6分32秒／1.87億回再生／音楽は AaronGrooves

### どんな話か

- 色違いの棒人間（緑・赤・青・黄・オレンジ）が、音の出るブロックで演奏バトルをする。
- **セリフはゼロ。** 画面の文字は、ゲームのメニューと最後の「The End」だけ。

### 流れ

| 時間 | 何が起きるか |
|---|---|
| 0:00 | 緑が1人で、ブロックを叩いて曲を弾いている |
| 0:10〜0:58 | 赤・青・黄が1人ずつ割り込んで見せびらかす → 緑が蹴り飛ばす |
| 1:00〜1:27 | 追い出された3人が「音楽の薬」を作って、ニワトリに飲ませる |
| 1:28〜3:15 | ニワトリが天才演奏家になり、緑と演奏バトル。3人は巨大な音楽タワーを建てる |
| 3:23〜4:24 | 全員でバンド演奏（ドラム・ベース・ピアノ・管楽器） |
| 4:25〜5:25 | ブロックでギターを作って、ギターバトル |
| 5:26〜5:54 | 演奏が激しすぎて、ステージが燃えて爆発 |
| 5:55〜6:08 | 隣の家で寝ていた人が起きてきて、全部止める（オチ） |

### 音との合わせ方

- **叩く＝1音。** キャラが何かを叩くたびに、その楽器の音が鳴って、音符が飛び出す。
- ドラム役は細かい拍に、ベース役は1拍目にだけ当てる。
- ギターの速いフレーズは、指の動きまでフレーズに合わせて描いている。

### 言葉なしで気持ちを伝える方法

- 腕組み＋足トントン＝イライラ。
- 手をこする＝悪だくみ。
- 寝そべって足を組む＝勝ち誇り。
- 動く直前に一瞬止める「タメ」で笑わせる。

### 権利

- マインクラフトのブロック・音・ニワトリは他社のもの。
- **使えるのは「型」のほう。** 色違いのキャラに1人1つの性格、音のバトルが大きくなっていく流れ、最後に全然関係ない人が止めるオチ。

## ② 言葉なしの感動ストーリーアニメ（数分の長尺）

**代表作：Silent Bonds Animation「SpongeBob Lost His Best Friend Over a Mistake…」**
https://www.youtube.com/watch?v=fOWOTip51pA
7分42秒／230万回再生

### どんな話か

スポンジ・ボブが、親友パトリックへのプレゼントを持っていく。
転んでパトリックのテレビを壊してしまい、絶交される。
家を出て砂漠をさまよう。
嵐の中、探しに来たパトリックが崖から落ちる。
スポンジ・ボブが泣きながら助けて、仲直りする。

### 本当に言葉なしか

- **ほぼ無言だけど、完全ではない。**
  - 「Help!」「Patrick! Wake up!」など、叫び声のセリフが数回ある。
  - 泣き声・息づかい・笑い声はずっと入っている。
  - 字幕・吹き出しはない。

### 流れ

| 時間 | 何が起きるか |
|---|---|
| 0:00〜1:07 | 幸せな朝。プレゼントを包んで、親友の家へ |
| 1:08〜2:11 | 転んでテレビを壊す → 背中を向けられる |
| 2:12〜4:15 | 荷物をまとめて町を出る。ブランコの思い出で泣く。親友も写真を見て後悔 |
| 4:16〜5:40 | 嵐。探しに出た親友が崖から落ちて気を失う |
| 5:41〜6:45 | 駆けつけて、泣きながら起こす → 抱き合う |
| 6:46〜7:40 | 嵐が晴れて月夜。一緒に帰って、毛布の秘密基地で笑う |

### 言葉なしで泣かせる方法

- **色：** 幸せな場面は金色の日差し、落ち込む場面は灰色と茶色、危ない場面は暗い青と稲妻、仲直りはろうそくの暖かい光。
- **回想：** 古いフィルムの枠と、セピア色の画面で昔の思い出を見せる。
- **小物：** 写真、プレゼント。
- **涙：** アップで、滝のような涙と震える口。
- **音楽：** ピアノ・アコギ・弦。泣く場面で盛り上げる。落ちる直前だけ雨の音と息づかいにする。
- **カットの長さ：** 普通は3〜7秒。事件の場面は1〜3秒で速く切る。泣く場面は5〜10秒、じっくり見せる。

### 権利

- スポンジ・ボブは他社のキャラ（ファンアニメ）。
- **使えるのは「話の型」。** 大事な物を壊す → 誤解されて絶交 → 恥ずかしくて家出 → 命の危機 → 助けて本当の友情に気づく → 仲直り。
- これは、ぱっちゃんの朗読の「感動する話」とそのまま同じ骨組みです。

## ③ 自作の曲に合わせた高品質な3D音ハメ（Automa 型）

**代表作：Automa「Verity's Bizarre Physics Simulations」**
https://www.youtube.com/watch?v=ymDpUEBkJqI
9分20秒／公開4日で68万回再生

### どんな話か

- 黄色いニコちゃんボール（名前は「Verity」）に、20種類の物理実験をする詰め合わせ。
- 1つの実験は20〜40秒で、条件をだんだん強くしていく。
  - ガラス板の細かさ：1面 → 16,384面
  - 柔らかさ：0% → 100%
  - 重さ：1kg → 1000kg → 太陽より重い
  - 液体：水 → 牛乳 → はちみつ → 酸 → 溶岩
- 最後はメントス＋コーラで大爆発。

### 音との合わせ方

- 1〜2コマ単位で、曲の拍に合わせている。
  - 強い拍：ガラスが割れる、液体がはじける、着地する
  - 弱い拍：落ちている途中、2回目のバウンド、文字の切り替わり
  - 休み：笑いのひと言を入れて、次の当たりまでタメる
- 曲は速いテンポのチップチューン（ファミコンっぽい電子音）。

### 想定と違ったところ（大事）

- **言葉なしではない。** 合成音声のひと言ギャグが入っている（「Hi Nokia, I'm Verity」など）。
- **他社の物がたくさん出てくる。** マインクラフトのベッド・クリーパー、Backrooms、ハギーワギー、ノキアの携帯、ビットコイン。
- Tunetastic にも「Verity」の動画があるので、Verity はネットで流行っているキャラかもしれない。
- 前回のレポートでは「自作の曲で権利がきれい」と書きました。でもこの動画は、曲以外のところで他社の物に頼っています。
  → 「Automa 型」とは「音ハメの精度と、条件をだんだん強くする構成」のこととして考えます。

### 使える型

- 1つの実験を20〜40秒にして、条件を5〜8段階で強くしていく → 最後に一番ばかばかしい段階。
- 主役のボールにも顔があって、表情で笑わせる。
- パステルの背景に、つるつる・ぷにぷに・ガラス・液体の質感。
