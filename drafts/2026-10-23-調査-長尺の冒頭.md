# 長尺の冒頭の作り方（2026-10-23）

オーナーの声：「冒頭が突然始まってびっくりした」。
それを受けて、長尺の冒頭をどう作るかを調べました。Shortsの冒頭については `2026-10-16-調査-冒頭と収益化.md` にまとめてあります。

## 何が起きていたか（測った数字）

- 0〜0.4秒は完全な無音でした（デジタルの無音）。
- 0.4秒の最初の音は RMS −13 dBFS でした。動画全体の平均（−15.6）より大きい音です。
- タイトルと曲当てのカードも、同じ瞬間に出ていました。

無音からいきなり大きな音が鳴るので、びっくりします。

## 分かったこと

【公式】は YouTube の公式ページ、【専門家】は名前の出ている専門家、【二次】はブログや報道です。
公式ページは直接開けなかったので、検索結果の抜粋で確かめています。

- **0:30まで残った人の割合が「冒頭」の成績です。** 普通の冒頭は約30秒で、50%以上残れば「平均より上」です【公式】。
- **長い前置き、ロゴ、タイトルカードは離脱の原因です。** 最初の場面そのものを見せ場にします【公式：Rene Ritchie、Creator Playbook】。
- **0〜7秒で「この動画で合ってる」と思わせます**【専門家：Colin & Samir】。
- **ホームや検索では、動画は音なしで自動再生されます**【公式】。最初の数秒は、音なしでも何の動画か分かる絵にします。
- **テレビでは、プレビューが音ありで流れることがあります**【二次】。自動再生で次の動画から来た人も、最初から音が出ています。だから冒頭で大きな音を急に鳴らしません。
- **大きな音の30〜500ミリ秒前に小さな音があると、びっくりが減ります**（プレパルス抑制）【学術】。
- **YouTube は大きすぎる音を下げますが、小さい音は上げません**（目安 −14 LUFS）【専門家の測定】。だから「無音 → 大音量」の差は、再生のときもそのまま残ります。
- **音楽を聴く人は飛ばすのが早いです。** 再生の約24%が、最初の5秒以内に飛ばされます【専門家：Spotifyのデータ】。音楽が始まるまでは3秒以内にします。
- **再生回数の多い装置系の動画は、小さなきっかけから始まります。** 記事の記述によると、Marble Machine はハンドルを回すところ、OK Go のピタゴラ装置はおもちゃのトラックがドミノを押すところ、Joseph's Machines はコーヒーを一口飲むところから始まります。どれも、そこから音楽が育つ形です【二次】。

## 新しい冒頭（3.0秒）

| 時刻 | 絵 | 音 |
|---|---|---|
| 0.0秒 | 1ページ目の上が全部見える引きの絵。ろうそく、振り子、ゲートの奥で待つビー玉、壁に刻んだタイトル「300 Years of Music / one marble」 | 部屋の空気の音が、0.8秒かけてふわっと入る |
| 0.2〜2.4秒 | 振り子が揺れ、カメラがゆっくり寄っていく | カノンのテンポで「チク・タク」が5回。少しずつ大きくなる |
| 1.32秒 | 3回目のチクでゲートが開き、ビー玉が転がりだす | ゲートの留め金の小さな音と、転がる音 |
| 3.0秒 | ビー玉が最初の音符に落ちる | カノンの最初の音。半分の音量から始めて、約5秒かけて元の音量に戻す |

- 最初の音は RMS −18.7 dBFS になりました（前は −13.3）。それまでのチクタクは −37〜−44 dBFS です。
- 部屋の空気の音（約 −52 dBFS）は、動画全体の下でずっと鳴らします。無音の瞬間をなくすためです。
- 画面に重ねていたタイトルはやめて、壁に刻みました。曲当てのカードと重ならなくなります。
- チャプターは2.6秒ずつ後ろにずれました（00:21 / 00:50 / 01:40）。

4本に共通していたこと：

- 最初の音は1〜2秒。
- 最初の絵には、ひとつの物しかない。背景は無地（白・灰・ベージュ）で、玉と楽器だけがはっきり見える。
- 最初の区間は、まっすぐなレールに楽器が等間隔に並ぶ。「当たる＝鳴る」が2秒で分かる。
- 楽器の名前を文字で出す（MARIMBA、Piano、Wind Chimes）。クイズ型は「1. ???」のあとに曲名が出る。
- カメラはカットなしの1本の流れで、玉を追う。
- 玉は4本とも、ふつうのつやつやしたガラス玉。顔も光の尾もない。玉のデザインで差をつけられる。

うちの冒頭への反映（v3）：

- 最初の絵は「ろうそく」と「ゲートの奥のビー玉」だけにした（寄りの絵）。振り子はやめた。
- 始まりが見えるようにした。ろうそくの火の粉がビー玉に飛び込む → ビー玉の中に炎がともる → 部屋が明るくなる → ビー玉がゲートを押す → ゲートが開く。
- ゲートは正面に赤い円盤を付けて大きくした。開くのが正面から分かる。
- 最初の音は3.6秒。競合より遅いが、その間ずっと「次に何が起きるか」が続く。
