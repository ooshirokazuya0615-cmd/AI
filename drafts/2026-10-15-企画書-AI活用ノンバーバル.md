# AIを使った言葉なしチャンネルの案（2026-10-15）

質問：参考動画の上位互換になるチャンネル、または新しい切り口で、AIを使ってノンバーバルチャンネルを作れるか。

調べたこと：AI動画ツールで今できること、AIで作った言葉なしチャンネルとYouTubeの最新ルール、参考チャンネルの弱点。4つの方向から8案を出し、ポリシー・独自性と、伸びやすさ・作りやすさの2つの目で採点しました。

---

## 1. 答え

**作れます。ただし「AIに動画を丸ごと作らせる」形ではありません。**

拍・物理・音は、僕のコードでフレーム単位で正確に決めます。AIに描かせるのは、背景の美術と、タイミングの要らない景色だけです。この役割分担そのものが「上位互換」の中身になります。

AIに丸ごと作らせない理由は3つです。

1. **動画AIは拍を知りません。** 出力は24fpsで、曲のテンポを知りません。業者の試験（2026年8月）では、ぶつかる・つかむといった接触の動きはどの Veo でも正しく出ず、連鎖する因果は約50%しか成功しませんでした。
2. **AIだけの量産は、YouTube の取り締まりのど真ん中です。** 2026年1月には、AIの量産チャンネル16〜18本（登録者は合計約3,500万人）が削除されました。2026年7月には、収益化できない「不自然なコンテンツ」が3つに分けて説明されました。本業の朗読チャンネルまで巻き込む危険があります。
3. **AIが自動で作っただけの絵には、著作権が付かない可能性が高いです。** キャラ・旋律・話は人が作る側に置かないと、資産になりません。

正直に言うと、言葉なしのオリジナルキャラが速く伸びるという証拠は、まだありません。伸びは年単位と見てください。

## 2. 上位3案

3案とも同じ「夜の古い家」の世界でつながっていて、1つのチャンネルの中の別々のシリーズとして作れます。

### 1位　タマと鳴る家（上位互換）

ビー玉のタマが古い家の道具を鳴らして、1曲を完成させる、言葉なしの音ハメ物語です。拍・物理・音はコードが決め、家の美術はAIが描きます。月1本、10〜15分の「夜の演奏会」も同じ世界で作ります。

**どこが上位互換か**
- **Virtual 3D（284万人）・Tunetastic（163万人）より**：「当たると鳴る」入口は同じです。違うのは、ミーム曲やカバーを使わずオリジナル曲と著作権の切れた曲だけを使うこと、毎回出る主役と結末のある話があること、動きを譜面から逆算した物理で作ることです。
- **Oddbods・Larva より**：あちらは子ども向けで、音ハメもありません。こちらは大人向けの「映画のミニチュア」の絵です。
- **AIだけで作るチャンネル（Kitty Fun TV、Mischief Time など）より**：あちらは音符ちょうどの接触を作れません。
- **10/14の企画書（コードだけ）より**：いちばんの弱点だった「並べると絵が薄い」を、AIの美術で埋めます。

正直なところ、視聴者にとって新しくなるのは主に見た目の豊かさです。キャラが登録の理由になるかは、まだ確かめていません。

**回の例**
- 「冬至の夜、時計が遅れる」：寒さで長老（柱時計）のぜんまいが渋り、時報が遅れていきます。火箸が足りない拍を代わりに刻み、最後の時報がぴたりと合います。
- 「風鈴が来た夜」：同じガラスでも、タマと風鈴は鳴り方が違って合いません。タマは風の切れ目に自分の音を置いていき、やがて二重奏になります。
- 長尺「夜の演奏会 第1夜」：3つの部屋で、オリジナル2曲とPD曲1曲を、部屋ごとにちがう道具の仕掛けで演奏します。曲の合間に、いなくなった火箸の片方を探す小さな話が進みます。

**作り方**
- **AI**：Blender で作った灰色の仮の部屋の映像を、Gemini Omni Flash か MiniMax H3（どちらも手持ちの動画を描き直せる動画AI）で「ミニチュア映画風」に描き直します。良い1コマを静止画にして、コードで部屋の形に貼り付けます。静止画なので、AI動画にありがちなちらつきやタイミングのずれが起きません。
- **コード**：タマ、動き、物理、音、光。AIにはタマを描かせません。
- **オーナー**：話の結末、主旋律の鼻歌、キャラの最終決定、AI背景の採用・不採用。

**費用と時間**（クレジットは推定で、信頼度は低いです）
- シーズンに1回の背景づくり：約90〜220クレジット
- 45秒のショート1本：オーナー6〜20時間、クレジット0〜100
- 月の目安（ショート4〜6本＋演奏会1本）：約100〜450クレジットで、月2,000に収まる見込み

**主なリスク**
- 「ビー玉が曲を弾く」は既存の形に見えやすい → 楽器が話の目的（直す・届ける・起こす）から生まれる回だけを出します
- AIの夜の日本家屋は、ジブリや新海誠の背景に寄りやすい → デザイナーの美術ボードを参照にし、作家名を指示文に入れず、採用前に見比べます
- かわいいガラス玉は子ども向けと判定されやすい → 大人向けの照明と色にし、最初の公開前に専門家に確認します

採点：ポリシー・独自性 7.5（8案で1位）、伸びやすさ・作りやすさ 6.5

### 2位　よふけの家・1時間版（環境音チャンネルの上位互換）

同じ古い家の夜を、約1時間ほぼ実時間で流す長尺です。雨・雪・虫の声が夜明けに向けて静かになり、そのあいだにキャラの小さな出来事が起きます。眠るとき、作業中、テレビでつけっぱなし、のどれにも使え、ループはしません。

**どこが上位互換か**
- Ambient Worlds（120万人、1年17本で長尺4,600万回）は、他人の作品の世界を借りていて、映像もほぼループです。こちらはオリジナルの家とキャラで、時間が本当に進み、出来事が起きます。
- Nature Sounds nagomi（17.1万人、登録者は1年で+42.5%）は本物の自然音です。こちらもオーナーが録った音を土台にし、そこにキャラと季節の出来事を足します。
- 睡眠用の動画には「途中の広告で起こされる」という不満があります。途中の広告をオフにして答えます。
- 調査でいちばんはっきりした「長く見られる型」は、用途のある長尺です。2027年からの収益化の条件（1年で8,000時間）にも、いちばん近い道です。

**回の例**：「雨だれの夜（梅雨）」「初雪の夜（冬）」「台風の目の夜（夏の終わり）」

**作り方**：家の中と雨・雪はコード。AIは、窓の外の星空など差がはっきり出る景色だけ（1晩の1割以下）。土台の音は、オーナーが自宅まわりで録った雨・虫・風です（必須）。

**費用と時間**（推定）：1晩あたりオーナー6〜9時間、クレジット0〜80。録音機が要るなら最初に¥1.5万〜4万。

**主なリスク**：静止画のスライドショーに見えると「手間の少ない繰り返し動画」に当たります。出来事を10分以上入れ、5〜10分ごとに新しい描画を入れます。単独のチャンネルにはせず、1位と同じチャンネルの「静かな物語」シリーズにします。

採点：ポリシー・独自性 5、伸びやすさ・作りやすさ 7（8案で1位）

### 3位　音の発見回（新しい切り口）

古い音叉のキャラ「オンサ」が、共鳴・うなり・クラドニ図形（音で砂が模様を描く現象）といった本物の音の現象を、言葉なしで見つけていきます。キャラの気持ちを本物の現象で表します（近い音とずれて震える「うなり」が笑い、同じ高さの相手と鳴り合う「共鳴」が友情）。

**なぜ新しいか**：Alan Becker の「Animation vs. Math」は、言葉なしで「調べられる題材」を扱い、3年後も見られ続けています。こちらは題材を「耳で確かめられる物理」にします。言葉なし×決まったキャラ×本物の音の物理、という組み合わせは見つかりませんでした。現象はコードで計算するので、AIには作れません。

**回の例**：「クラドニ図形」「共鳴（感動回）」「重さが半分の部屋のふりこの波」

**弱点**：有名な実写の実験動画が検索上位にいます。扱える現象も20前後です。年に数本の「発見回」として、1位の世界に入れます。

採点：ポリシー・独自性 6.5、伸びやすさ・作りやすさ 5

## 3. 見送った案

- **本物の「できるまで」**（AI工場ASMRの上位互換）：偽の工場映像が問題になっているジャンルの隣に置かれます。クレジットも8案で最大でした。
- **七十二候の箱庭**：文化としては本物ですが、旬が5日のショートは長く見られる型と逆向きです。AIの苔や露の接写は、AIの癒やし動画と同じ見た目になります。季節の題材として2位に合流させます。
- **ゆめに入る音**：フックは8案でいちばん強いです（目覚ましの音が夢に混ざる）。でも夢の部分がAIのシュールな絵で、AI動画の棚に並びます。5本に1本以下の特別回なら可とします。
- **からくり音楽会（単独チャンネル）**：単独だと Virtual 3D などと同じ形に見えます。1位の「演奏会」として入れます。
- **AIで丸ごと作る量産型**（AIの動物ショート、AIの切るASMR、ミームのモンスター）：取り締まりの対象そのものです。

## 4. AIを使うときのルール（要点）

1. タイミングはAIに決めさせません。拍・接触・物理・音は、すべてコードで作ります。
2. AIは主役から遠い層だけに使います（背景の美術、景色）。タマなどの主役はAIに描かせません。
3. AIが付けた音はすべて捨てます。AIの作曲機能も使いません。旋律はオーナーの作曲か、権利の切れた曲だけです。
4. 明らかに現実ではない「ミニチュア映画」の絵を守ります。本物と見間違える映像は作りません。
5. AIを使っても本数は増やしません。投稿は手動です。
6. 開示は正直にします。About に「背景美術の一部はAI」と書きます。「AI不使用」とは名乗りません。
7. 生成の記録（モデル、指示文、参照画像、採用したか）を永久に残します。
8. テストのアップロードは新しいチャンネルだけで行います。本業のチャンネルには上げません。

## 5. 最初のテスト：AI美術の効き目テスト（10/22まで）

**分かること**：vidIQ の本当の料金、手元の映像を vidIQ に渡せるか、AIの背景でコードだけの絵より良くなるか。

| 手順 | 中身 | クレジット（推定） |
|---|---|---|
| 0 | 灰色の仮の部屋の映像（4秒）を作り、vidIQ に取り込めるか確かめる | 0 |
| 1 | いちばん安いモデル（veo-3.1-lite）で4秒を1本作り、残高の減りから本当の料金を測る | 約4 |
| 2 | 灰色の映像を Omni と H3 で1回ずつ描き直し、静止画にして投影。コードのタマが4拍で器を叩く12秒を、コードだけの版と並べる | 約20〜50 |
| 3（任意） | タマを抜いた決めショットだけ H3 に通して比べる | 約8〜15 |

- **合格の線**：スマホで見て背景が揺れない・ずれない。初見10人のうち7人以上がAI美術版を選ぶ。届かなければ、10/14のコードだけの道に戻ります。
- **合計**：約25〜70クレジット（推定）。10/30の補充の前に、100以上を残します。料金が推定の5倍でも、手順2と3は合計80クレジットで止めます。
- **お金**：0円（見比べの協力者への謝礼は別）。

## 7. AIツールの事実（出典つき）

- vidIQ の動画生成の料金は「秒数×モデルの秒単価×20クレジット」です。秒単価は公開されていません。生成に失敗すれば返金されます（vidIQ のツール仕様）。
- Veo 3.1 の価格は、標準が$0.40/秒、Fast が720pで$0.10/秒、Lite が720pで$0.05/秒です（[Gemini API の価格表](https://ai.google.dev/gemini-api/docs/pricing)、検索結果の要約）。
- Veo の出力は24fpsで、参照画像は「強い提案」にとどまります。接触の動きは正しく出ず、連鎖する因果は約50%の成功でした（[invideo の検証](https://invideo.io/faq/how-accurately-do-ai-video-generators-simulate-physics/)、[Physics-IQ の研究](https://arxiv.org/abs/2501.09038)）。
- Gemini Omni Flash は元の解像度が720pで、編集を約4回重ねると細部がずれ始めるという報告があります。MiniMax H3 は動画→動画の変換でクリップ全体を作り直し、入力の映像も課金されるという情報があります（第三者のレビュー）。
- vidIQ の外には、Runway Aleph 2.0（動画の描き直し、約$0.28/秒）や、借りたGPUで動かす Wan 2.1 VACE もあります（各社の案内）。
- Sora はアプリが2026-04-26に、APIが2026-09-24に終了しました（[OpenAI ヘルプ](https://help.openai.com/en/articles/20001152)）。
- Mischief Time は、Blender で背景と小物を作り、AI（ComfyUI）でキャラを動かす分担だとチャンネル説明に書いています。
- YouTube は2026-05-27から、写実的なAIの使用を検出すると自動でAIラベルを付けています。明らかに現実ではないアニメには開示は要らないとしています（[TechCrunch](https://techcrunch.com/2026/05/27/youtube-will-now-automatically-label-ai-videos/)）。
- 2026年7月の説明で、収益化できない「不自然なコンテンツ」は、繰り返し・テンプレート的なもの、不快・満足できないもの、敏感な話題のAI人格、の3つに分けられました。AIを使うこと自体は違反ではありません（[Tubefilter](https://tubefilter.com/2026/07/13/youtube-inauthentic-content-monetization-policy-update/)）。
- 2026年1月、AIの量産チャンネル16〜18本（登録者合計約3,500万人）が削除されました（[Tubefilter](https://tubefilter.com/2026/01/29/youtube-ai-slop-channel-crackdown-bans/)）。
- AIラベルの付いた投稿は反応が約7%減りますが、技術が要る使い方だと見られると、この減り方はほぼ消えるという研究があります（Journal of Consumer Research）。

注意：YouTube と Google の公式ページは、この環境から直接開けませんでした。多くは検索結果の要約と第三者の記事からの情報です。
