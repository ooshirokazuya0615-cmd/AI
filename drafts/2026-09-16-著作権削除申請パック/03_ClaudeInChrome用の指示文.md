# Claude in Chrome で削除申請を進める手順

## 準備（1回だけ）

1. Chrome に「Claude in Chrome」拡張を入れて、claude.ai のアカウントでサインインする。
2. 嫁子チャンネルの Google アカウントで YouTube Studio にログインし、次のURLを開いておく。
   https://studio.youtube.com/channel/UCYASX2PAaV_7aEX6EPpP8Dg/copyright
3. 拡張のサイドパネルを開く。

## 1申請ごとの流れ

1. `04_申請ラウンド1.txt` から1ブロック（=== で始まる1チャンネル分）をコピーする。
2. 下の指示文の【ここにブロックを貼る】に貼って、サイドパネルに送る。
3. Claude が「削除対象の動画」の入力まで進めたら、内容を目で確認して、手順2以降と送信はお客様が押す。

## 指示文（コピペ用）

```
YouTube Studio の著作権ページを開いています。以下の転載動画について、新しい削除リクエストを作成してください。

【ルール】
- 「著作権」→「削除リクエスト」→「新しい削除リクエスト」を開く
- 「削除対象の動画」に、下のブロックの侵害動画URLを1本ずつ追加する。各動画で「著作権侵害を受けた作品」は「動画」、「作品のタイトル」は元タイトル、「作品のURL」は元動画URL、「侵害箇所」は「動画全体」を選ぶ
- 「著作権侵害の内容」欄には次の文を入れる：
  当チャンネル「嫁子のスカッと朗読劇場【スカッとする話】」（https://www.youtube.com/channel/UCYASX2PAaV_7aEX6EPpP8Dg）が制作・公開しているオリジナルの朗読動画（脚本・ナレーション音声）を、許諾なく複製して投稿したものです。動画タイトルおよびナレーション音声が当チャンネルの元動画と同一であり、当チャンネルの公開日の方が先です。
- 申請者情報と法的同意のページに進んだら、そこで止まって私に知らせる。送信ボタンは押さない
- 入力に迷う項目があれば、推測せずに聞く

【ここにブロックを貼る】
```

## 注意

- **送信は毎回自分で押す。** 申請者情報（氏名・住所・電話・メール）は相手に開示されるので、初回は「自分の会社」を選ぶか個人名にするかを決めてから。
- 出す前に侵害動画を10秒再生して、ナレーションが嫁子の音声であることを確認する。虚偽申請は自チャンネルの停止リスクになる。
- 1日の申請数が多すぎると YouTube 側で一時的に受付が止まることがある。1日30〜50申請を目安に。

## ラウンドの進め方

| ラウンド | 内容 | 出すタイミング |
|---|---|---|
| 1 | 上位100チャンネルに1本ずつ＋101位以降はまとめて | 今すぐ |
| 2 | 上位100チャンネルにもう1本ずつ | ラウンド1の削除が実行され、相手に警告が付いた後（目安1週間後） |
| 3 | 上位100チャンネルにもう1本ずつ。ここで相手チャンネル停止 | ラウンド2の削除実行後（目安さらに1週間後） |

ラウンド3で停止したチャンネルの残り動画は自動的に消えるので、個別申請は不要。
停止にならなかったチャンネル（警告が統合された等）は、01のシートから残りを申請する。
