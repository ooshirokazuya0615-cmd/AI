# YouTube Studio 著作権削除申請 手順と定型文

対象：嫁子のスカッと朗読劇場【スカッとする話】の転載 2,412本（819チャンネル）
同梱：01_チャンネル別URLシート_上位100.txt（1,094本）、02_残りチャンネルURL一覧.txt（1,318本）

## 先に決めること

- **申請者名は相手に開示される。** 削除通知を受けた投稿者には申請者の氏名（または会社名）とメールアドレスが渡る。個人名を出したくなければ「会社名」欄に法人名を入れ、連絡先は業務用メールにする。
- **虚偽申請はチャンネル停止のリスクがある。** タイトル一致だけで出さず、1本ずつ10秒でよいので再生し、音声（ナレーション）が嫁子のものだと確認してから出す。一致率100%のものはほぼ確実だが、確認は省かない。
- 先に公開されていた11本（全件調査ファイルの末尾C表）は申請対象から外してある。

## 申請の順番（効率順）

1. **Copyright Match Tool を先に見る。** Studio 左メニュー「著作権」→「一致する動画」タブ。音声一致で自動検出されたものが並ぶので、チェックを入れて「削除をリクエスト」でまとめて出せる。ここで拾える分は手入力不要。
2. 残りは「著作権」→「削除リクエスト」→「新しい削除リクエスト」。1回の申請に動画を複数追加できる。**削除だけが目的なら1チャンネル分を1申請にまとめる**（01のシートが1チャンネル1ブロックになっている）。**相手チャンネルを停止させたいなら、3回に分けて日を空けて出す**（下の「申請後」を参照）。
3. 上位100チャンネル（1,094本）を先に処理する。1〜3本しかない残り719チャンネルは、削除より「チャンネルを報告 → スパム」の方が早い場合がある。

## フォームの入力内容

### 手順1「削除対象の動画」

各動画ごとに以下を入力。01のシートの1行がそのまま1動画分。

| フォームの欄 | 入れる内容 |
|---|---|
| 侵害コンテンツのURL | シート1列目（転載動画のURL） |
| 著作権侵害を受けた作品 | 「動画」を選択 |
| 作品のタイトル／説明 | 元動画のタイトル（シート4列目） |
| 作品のURL | シート2列目（嫁子の元動画URL） |
| 侵害箇所 | 「動画全体」 |

### 手順2「著作権侵害の内容」— 定型文（コピペ用）

> 当チャンネル「嫁子のスカッと朗読劇場【スカッとする話】」（https://www.youtube.com/channel/UCYASX2PAaV_7aEX6EPpP8Dg）が制作・公開しているオリジナルの朗読動画（脚本・ナレーション音声）を、許諾なく複製して投稿したものです。動画タイトルおよびナレーション音声が当チャンネルの元動画と同一であり、当チャンネルの公開日の方が先です。脚本は当チャンネルが外部ライターに委託して制作したオリジナル作品で、音声も当チャンネルが収録したものです。

### 手順3「申請者情報」

- 権利者名：「自分」または「自分の会社」を選択（会社名を出す場合はここで法人名）
- 氏名・住所・電話番号・メールアドレスを入力。メールは業務用を推奨。
- 「私は著作権者本人、または著作権者から代理権を付与された者です」にチェック

### 手順4「法的同意」

3つのチェックボックスすべてにチェックし、氏名を署名欄に入力（申請者名と同じ表記）。

## 申請後

- 削除は通常1〜3営業日。相手が異議申し立て（カウンター通知）をすると10営業日以内に訴訟提起の意思表示を求められる。連番アカウントの業者は異議を出さないことがほとんど。
- 削除が実行されると相手チャンネルに著作権侵害の警告が付く。ただし**1回の削除リクエストに複数動画をまとめた場合、警告は1回にまとめられることがある**（同じ申立人が同時期に出した複数リクエストも統合されることがある）。
- 相手チャンネルを停止させたい（警告3回）場合は、**3回の削除リクエストに分け、日を空けて出す**。1回目の警告が付いたのを確認してから2回目、さらに確認してから3回目。3回目で相手チャンネルが停止され、残りの動画は全部消える。上位チャンネルは1回1本ずつ、計3本で足りる。
- 動画を消すだけでよければ、1チャンネル分をまとめて1申請で構わない（削除は本数分すべて実行される）。
- 申請後は Studio「著作権」→「削除リクエスト」タブで状況を確認できる。処理済みは全件調査CSVの該当行に「申請日」を追記して残す（再審査時の証拠になる）。

## 再発防止

- 元動画の概要欄に「本動画の脚本・音声は当チャンネルのオリジナルです。無断転載を確認した場合は著作権削除申請を行います」と一文入れておくと、Copyright Match Tool での判断が通りやすい。
- 月1回、全動画リスト（drafts/data）を使って同じ走査を回せば、新規の転載だけ差分で拾える。
