# 型：YouTube朗読シナリオ（スカッとする話）

## 使い方

```
templates/youtube-sukatto.md の型で、「（設定）」の朗読シナリオを書いて
```

## 大前提

**読み上げられる前提で書く。**
改行位置が、そのまま朗読の「間」になります。
文体プロファイルの改行リズムを、そのまま朗読の呼吸として使ってください。

黙読用の文章としてではなく、**声に出したときに気持ちいいか**で判断します。

## 構成

```
【冒頭30秒】
一番おいしい場面を先に少しだけ見せる。または強烈な一言から入る。
ここで離脱が決まります。説明から入らない。

【状況説明】
主人公が何者で、どんな理不尽な状況にいるか。
具体的に。「嫌な人」ではなく「毎朝5分遅れてくるのに、こちらの1分の遅刻を全員の前で指摘する人」。

【理不尽の積み上げ】
1つでは足りない。3つ重ねる。
視聴者が「これはひどい」と完全に納得するまで積む。
ここを省くとスカッとしません。

・・・

【溜め】
主人公が黙って耐えている描写。
心の声を「」で独立させて置く。

【反撃・逆転】
一気に落とす。ここは短く、テンポよく。
セリフ中心にする。地の文で説明しない。

【相手の反応】
うろたえる様子を具体的に。ここが視聴者の快感ポイント。

【後日談】
その後どうなったかを短く。
オチや余韻を(笑)や自虐で締める。
```

## 尺の目安

| 動画の長さ | 文字数の目安 |
|---|---|
| 5分 | 1,500〜1,800字 |
| 10分 | 3,000〜3,500字 |
| 15分 | 4,500〜5,000字 |

朗読は1分あたり300〜350字が目安です。

- [ ] 音読して息継ぎが自然な改行位置になっているか
