# 型：セールスレター

## 使い方

```
templates/sales-letter.md の型で、（商品名・価格・対象者）のセールスレターを書いて
```

## 先に埋めること

これが埋まっていないレターは書けません。先に決めてください。

| 項目 | |
|---|---|
| 商品・サービス名 | |
| 価格 | |
| 誰に売るか | どんな状況の、何に困っている人か |
| 手に入る結果 | 買った人がどう変わるか（数字で） |
| 実績・証拠 | 自分の数字、受講者の変化、期間 |
| 保証・特典 | |
| 締切・限定 | |

## 構成

```
【ヘッドライン】
結果＋対象＋期間を具体的に。数字を必ず入れる。

【つかみ】
読者の今の状況を、本人より具体的に描写する。
「わかってもらえてる」と思わせるまで、売らない。

・・・

【問題提起】
なぜ今までうまくいかなかったのか。読者のせいにしない。
「やり方を知らなかっただけ」に着地させる。

【解決策の提示】
ここで初めて商品を出す。
何ができるようになるかを、機能ではなく変化で語る。

【証拠】
・自分の実績（月商350万月収100万、のように具体的に）
・受講者の変化
・生活のディテール（服はGUやユニクロ、車はシェアカー…のように固有名詞で）

【オファー】
価格、内容、特典、保証。
価格の前に価値を積み上げきってから出す。

【締切・限定】
理由をセットで。理由のない限定は嘘くさくなる。

【背中を押す】
迷っている人の心の声を代弁してから、そっと押す。
煽らない。「安心してついてきてくださいね!」のトーン。

PS：一番の決め手をもう一度
PPS：締切の再提示
PPPS：それでも迷う人へ
```

## この型でのNG

- 煽りすぎ。この文体の持ち味は「親しい友達の丁寧語」。恐怖で売らない。
- 実績自慢だけで終わること。必ず「どん底からのV字」の文脈に乗せる。
- 抽象的なベネフィット。「人生が変わります」ではなく数字と生活のディテールで。

## チェック

- [ ] 価値を積み上げきってから価格を出しているか
- [ ] 実績が「どん底→V字」の文脈に乗っているか
- [ ] 限定・締切に理由があるか
- [ ] 読んで「怖い」より「安心」が勝つトーンか
