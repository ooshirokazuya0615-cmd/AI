# 型：ブログ記事

## 使い方

```
templates/blog.md の型で、「（テーマ）」の記事を書いて
```

## メルマガとの違い

ブログは**検索から来た初対面の人**が読みます。
メルマガのような「continuing の関係」を前提にできません。

- 冒頭の「%name1%さん、ぱっちゃんです。」は使わない
- 見出し（##）で構造を作る。メルマガの罫線ではなく見出しを使う
- 結論を先に出す。検索で来た人は答えを探している
- ただし**改行と空白行のリズムは同じ。** ここは絶対に崩さない

## 構成

```
【冒頭】
検索して来た人の疑問を、そのまま言語化して返す。
「〜で悩んでいませんか?」
そのあと、この記事で何がわかるかを3行で。

## 結論
先に答えを書く。

## なぜそう言えるのか
自分の体験。数字と固有名詞とセリフで具体的に。

## 具体的なやり方
・3〜4項目の箇条書きで
・それぞれ短くリズミカルに

## よくある失敗
自分がやらかした話を入れる。ここが一番読まれる。

## まとめ
結論をもう一度。行動喚起は1つだけ。
```

## チェック

- [ ] 初対面の人が読んでもわかるか（内輪ネタになっていないか）
- [ ] 結論を先に出しているか
- [ ] 見出しだけ読んでも中身がわかるか
- [ ] 段落が長くなっていないか（ブログでも2〜4行＋空白行）
