# 型：メルマガ（単発1通）

## 使い方

```
templates/melmaga.md の型で、「（テーマ）」のメルマガを書いて
```

## この型の目的

1通で「読み物として面白い」かつ「1つだけ持ち帰らせる」。
教えすぎない。1通1メッセージ。

## 構成

```
%name1%さん、ぱっちゃんです。

【つかみ】
日常の具体的なワンシーンか、読者の心の声の代弁から入る。
いきなり本題に入らない。3〜5行。

ーーーーーー

【本題への転換】
「さて、」「ですが、」を単独行で置いて話を切り替える。

【本題】
・エピソード（数字・固有名詞・セリフ入りで具体的に）
・そこから何に気づいたか
・読者にとってそれが何を意味するか

感情の頂点の直前には「・・・」か空白行で溜めを作る。

【行動喚起】
1つだけ。「なぜそれが大事か」の理由とセットで語る。
命令しない。背中を押す。

【締め】
「それでは、また明日の夜にメールしますね。」
「最後までお読み頂きありがとうございました。」

PS：一番言いたい行動喚起をもう一度、短く
PPS：追加のプレゼントや特典
PPPS：次回予告（引きを作る）
```

## この型でのチェック

- [ ] 1通で伝えたいことが1つに絞れているか
- [ ] つかみが「日常のワンシーン」から入っているか（説明から入っていないか）
- [ ] 具体的な数字か固有名詞が最低3つ入っているか
- [ ] セリフ（「」）が最低1つ入っているか
- [ ] PS まで書いたか
- [ ] スマホで見て2〜4行＋空白行のリズムになっているか
