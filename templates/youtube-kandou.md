# 型：YouTube朗読シナリオ（感動する話）

## 使い方

```
templates/youtube-kandou.md の型で、「（設定）」の朗読シナリオを書いて
```

## スカッと系との違い

| | スカッと系 | 感動系 |
|---|---|---|
| 快感の source | 逆転・反撃 | 気づき・報われる瞬間 |
| テンポ | 後半で一気に加速 | **最後までゆっくり。急がない** |
| 溜め | 反撃の直前 | **何度も。感情の波を作る** |
| オチ | (笑)や自虐で軽く | 静かに余韻を残す。ここで笑いに逃げない |

感動系で一番やりがちな失敗は、**説明しすぎること**です。
「泣ける」と言った瞬間に泣けなくなります。事実だけ淡々と置いて、判断は視聴者に委ねてください。

## 構成

```
【冒頭】
何気ない日常のワンシーンから。静かに入る。
後で意味を持つディテールを、ここでさりげなく置く（伏線）。

【関係性の描写】
登場人物同士の距離感を、行動で見せる。
「仲が悪かった」ではなく「10年間、同じ家にいて会話が3往復だった」。

【すれ違い・喪失】
何が失われたか、何がわからなかったか。
ここでも説明せず、場面で見せる。

・・・

【気づきのきっかけ】
手紙、遺品、第三者の一言など。
冒頭で置いた伏線が、ここで意味を持つ。

【感情の頂点】
セリフを1つだけ、独立させてドンと置く。
その前後は空白行で挟む。ここは短ければ短いほど効く。

【余韻】
その後の日常を短く描いて終わる。
オチをつけない。説明しない。静かに閉じる。
```

## 尺の目安

朗読1分＝300〜350字。ただし感動系は**間を多めに取る**ので、
同じ尺ならスカッと系より2割ほど文字数を減らして構いません。

## この型でのNG

- 「涙が止まりませんでした」のような、感情の直接描写。行動で見せる。
- 説明的な回想。場面として書く。
- 最後に教訓をまとめること。視聴者に委ねる。
- (笑)や自虐での締め。この型では使わない。

## チェック

- [ ] 冒頭に置いた伏線を後半で回収しているか
- [ ] 感情を「説明」ではなく「場面」で見せているか
- [ ] 感情の頂点が短いセリフ1つに集約されているか
- [ ] 教訓でまとめようとしていないか
- [ ] 音読したときに、間が十分に取れる改行になっているか
