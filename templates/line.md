# 型：LINE配信

## 使い方

```
templates/line.md の型で、「（テーマ）」のLINE配信を書いて
```

## メルマガとの違い

| | メルマガ | LINE |
|---|---|---|
| 長さ | 長くてよい | **短く。1配信300〜500字程度** |
| 冒頭 | 「%name1%さん、ぱっちゃんです。」 | 挨拶は省略か極短。いきなり本題 |
| 改行 | 2〜4行＋空白行 | **さらに細かく。1〜3行＋空白行** |
| 目的 | 読み物として成立させる | 1アクション取らせる |
| PS | PS→PPS→PPPS | 使わない。または1つだけ |

LINEは通知で開かれるので、**最初の1行で全部決まります。**
1行目に一番強い言葉を置いてください。

## 構成

```
【1行目】
一番強い一言。問いかけ、意外な事実、感情の一言。

【本文】
1〜3行のかたまり＋空白行を繰り返す。
言いたいことは1つだけ。

【行動喚起】
リンクを踏ませるか、返信させるか、どちらか1つ。
「〜してみてくださいね♪」で柔らかく背中を押す。
```

## チェック

- [ ] 1行目だけで開く価値が伝わるか
- [ ] 500字を超えていないか
- [ ] 1配信1アクションになっているか
- [ ] スマホ画面で見て、指1本でスクロールしきれる長さか
