# 型：ステップメール（連続配信）

## 使い方

```
templates/step-mail.md の型で、（テーマ）のステップメールを（N）通ぶん設計して
```

まず**全体設計だけ**を出させて、内容を確認してから1通ずつ書かせるのが失敗しないやり方です。

## 全体設計でまず決めること

| 項目 | 内容 |
|---|---|
| 読者の入口 | どこから登録した人か（どんな悩みを持っているか） |
| 出口 | 最終的に何をしてほしいか（商品購入／個別相談／継続読者化） |
| 通数と配信間隔 | 例：7通・毎日夜21時 |
| 各通の役割 | 下の型を参照 |

## 標準の役割配分（7通の例）

| 通 | 役割 | 内容 |
|---|---|---|
| 1 | 出会い | 自己紹介。ただし経歴自慢ではなく「どん底の日常」から始める |
| 2 | 共感 | 読者の今の状況を代弁する。「僕もそうでした」 |
| 3 | 転機 | 「ある日ふと気づいたんです。」の一文から、価値観が変わった瞬間 |
| 4 | 失敗 | 一度うまくいかなかった話。ここを飛ばすと信用されない |
| 5 | V字回復 | 師や気づきを得て変わった話。数字を具体的に出す |
| 6 | 対比 | 変化後の生活を、1通目の日常と対比で描く |
| 7 | 提案 | ここで初めて行動喚起。理由をセットで語る |

## 全体を通して守ること

- **1通目と最終通で対比が成立していること。** 1通目の「どん底の日常」が、最終通の「今の生活」と鏡になるように書く。
- **通ごとに引きを作る。** 各通の PPPS で次回予告を入れて、続きを読ませる。
- **伏線を回収する。** 前半で軽く触れた話（人物、失敗、口癖）を後半で拾う。
- **売り込みは最後だけ。** 6通目までは価値提供に徹する。

## チェック

- [ ] 1通目と最終通が対比になっているか
- [ ] 失敗の話（4通目相当）が入っているか。ここを省いていないか
- [ ] 各通に次回予告があるか
- [ ] 全体を通してキャラがブレていないか（一人称、口癖、テンション）
