# 型：サムネのコピー案出し

## 使い方

```
templates/thumbnail-copy.md の型で、「（あらすじ）」のサムネコピーを10案出して
```

画像より先に、**言葉を決めます。** ここでクリック率のほとんどが決まります。

## 出力形式

案ごとに、そのまま `tools/thumbnail.mjs` に渡せるJSONで出すこと。

## コピーの型（スカッと系）

| 型 | 例 |
|---|---|
| **セリフ→返し** | 義母「[出て行け]」→ 私「[どうぞ]」 |
| **立場の逆転** | 見下してきた同期が、[私の部下]になった日 |
| **数字の落差** | 月給18万の私が、[年収3000万]の社長だと知った瞬間 |
| **隠された事実** | 私を追い出した family。この家、[名義は私]でした |
| **第三者の介入** | 店員を怒鳴る客。後ろに立っていたのは[その人の上司] |

## コピーの型（感動系）

| 型 | 例 |
|---|---|
| **時間＋発見** | 10年間、会話しなかった父の[最後の手紙] |
| **数の重み** | 亡くなった母の引き出しに、[47通の未投函] |
| **すれ違いの正体** | 冷たいと思っていた祖母が、[毎晩していたこと] |
| **最後の一言** | 何も言わなかった父が、一度だけ言った「[ありがとう]」 |

## ルール

- **1行12文字以内、3行まで。** スマホでは320×180に縮む
- **`[ ]` は1〜2箇所。** 一番感情が動く単語だけ
- **答えを書かない。** 「〜だった理由」で止める。理由は動画の中に置く
- **数字を入れる。** 「長年」より「10年間」、「たくさん」より「47通」
- **煽りすぎない。** 中身と食い違うサムネは、再生後の離脱で結局マイナスになる

## 案出しのときの並べ方

10案出すときは、**型をバラけさせる**こと。
同じ型の言い換えを10個並べても選べません。上の表から違う型を最低5種類使ってください。
