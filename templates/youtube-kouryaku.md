# 型：YouTube攻略チャンネル台本（星野／解説・講義動画）

## 使い方

```
templates/youtube-kouryaku.md のワークフローで、「（章）」の文字起こしを台本に整えて
```

ターゲット・方向性・構成は、属人YouTubeグループ（チャットワーク）で決めます。
この型が扱うのは、**構成が決まったあと、台本の文章を作る工程**だけです。

## いままでのやり方と、何が起きたか

```
本人のアウトライン（1,300字）
  → AIが完全台本に膨らませる（30,000字）
  → 添削で「AI臭」が17件つく
  → AIで脱臭（v4、v5、リライト案）
  → まだAI臭い
```

膨らませた分がAIの文で、AI臭はそこに出ます。
脱臭は「AIの文をAIで磨く」なので、話の組み立てがAIのまま残ります。
詳しい実例は `style/ai-smell.md`。

## 新しいワークフロー：AIに書かせない。本人が喋る。AIは削って並べる

```
Step 0  構成（人間・チャットワークのグループで決定済み）
Step 1  喋る（人間・録音）
Step 2  文字起こし（機械）
Step 3  整える（AI・禁止事項つき）
Step 4  チェック（機械＋音読）
Step 5  収録用に整形（画面指示・データ番号）
```

### Step 0：構成

目次と、章ごとに「言いたいこと1つ」「見せる画面」を箇条書きにする。
`【2026年8月最新版】…` の元アウトライン（0：はじめに〜目次7項目）の粒度で十分。
ここでは文章を書かない。

### Step 1：喋る

章ごとに、スマホのボイスメモで録音する。

- 台本なし。手元に Step 0 の箇条書きと、数字のメモだけ
- 相談に来た人に、目の前で説明するつもりで喋る
- 1章5〜10分。詰まっても、言い直しても、そのまま続ける
- 比喩・たとえ話・口癖は、ここで出たものだけが台本に使える
- 60分の動画なら、録音は合計60〜90分になる

**ここが一番大事な工程です。** ここを飛ばしてAIに書かせると、元に戻ります。

話し忘れた章があっても、AIに書かせない。
AIに「この章で視聴者が聞きたい質問を10個出して」と頼み、その質問に答える形でもう一度録音する。

### Step 2：文字起こし

録音をそのまま文字にする。フィラー（えー、あの）も残す。
`drafts/raw/YYYY-MM-DD-章名.txt` に保存する。
これが照合の元になるので、消さない。

### Step 3：整える（AIの仕事はここだけ）

AIに渡すのは、文字起こしと、この指示。

```
以下は本人が喋った文字起こしです。台本に整えてください。

やっていいこと
・フィラーと言い直しを取る
・順番を入れ替える
・重複を削る
・読み上げの間に合わせて改行する（1行15〜25字、意味のかたまりごとに空白行）
・【画面：〇〇】の指示を足す
・指定の尺に収まるように削る

やってはいけないこと
・本人が言っていない主張、比喩、たとえ話、キメ台詞を足す
・「〜と思った人いますよね」の代弁を足す
・「先に言っておくと」「あとで回収します」の予告を足す
・章の終わりに「まとめます」を足す
・「AじゃなくてBです」の言い回しに書き換える
・漢語の名詞（点検項目、付加価値、再現性）に言い換える
・文字数を増やす。台本の文字数は文字起こし以下にする
・他の発信者や競合に触れる
```

出力の文字数が文字起こしより増えていたら、AIが足している。やり直し。

### Step 4：チェック

機械で拾う。

```
node tools/ai-smell-check.mjs drafts/台本.md --source drafts/raw/文字起こし.txt
```

| 指標 | 目安 |
|---|---|
| AI臭の検出 | 1,000字あたり1.0件以下 |
| 文字起こしに無い文 | 全体の10%以下 |
| 同じ文の繰り返し | 0 |

数字が通ったら、本人が音読する。
「自分はこう言わない」と感じた行に印をつけて、**本人の言い方で**直す。
AIに「ここを自然にして」と頼まない。それが脱臭ループの入口です。

### Step 5：収録用に整形

ここで初めて、画面指示・音声指示・データ番号（【データ①】など）・尺のタイムスタンプを入れる。
Step 3までは本文だけを扱い、演出指示を混ぜない。混ぜると本文の点検ができなくなります。

## 尺の目安

話す速さは人によって違うので、**Step 1 の録音から実測する**。
（録音の文字起こしの文字数 ÷ 録音の分数 ＝ その人の1分あたりの文字数）

参考：過去の台本では「550〜600字/分」と「約300字/分」の両方の前提が混在していました。
録音で測れば、この食い違いは消えます。

## 版の管理

Googleドキュメントのタブで v1、v2.1、v3、本文のみ、AI脱臭版、手動調整…と並べない。
どれが最新か分からなくなり、脱臭のたびに別のAI文が生まれます。

- 台本は1ファイル1版。古い版は消す
- 履歴が必要なら、このリポジトリの `drafts/` に置いて git で追う
- 文字起こし（`drafts/raw/`）だけは、最初の1回のものを残す

## この型でのNG

- アウトラインからAIに完全台本を書かせる（一番やってはいけない）
- AI臭い箇所を、AIに直させる
- 「もっと自然に」「人間らしく」とAIに頼む（AI臭の型が別のAI臭の型に変わるだけ）
- 数字の演出（「1円も入ってません」など）をAIが足す。数字は本人の言葉のまま

## チェック

- [ ] 台本の文字数が、文字起こしの文字数以下か
- [ ] 台本にある比喩・たとえ話は、全部文字起こしにあるか
- [ ] `ai-smell-check` で1,000字あたり1.0件以下か
- [ ] 悩みの代弁は1本に1回以内か
- [ ] 「まとめます」「先に言っておくと」「全部潰します」が無いか
- [ ] 本人が音読して、引っかかった行がゼロになったか
- [ ] 数字が本人の実績と一致しているか（月2,000万か3,000万か、8月版か9月版か）
