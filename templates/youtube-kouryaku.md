# 型：YouTube攻略チャンネル台本（ノウハウ解説）

## 使い方

```
templates/youtube-kouryaku.md の型で、「（テーマ）」の攻略動画の台本を書いて
```

## 朗読シナリオとの違い

| | 朗読シナリオ | 攻略台本 |
|---|---|---|
| 語り手 | 主人公（物語の中の人） | **僕（ぱっちゃん本人）** |
| 快感の source | 逆転・気づき | 「自分にもできそう」と思えること |
| 冒頭 | おいしい場面を先に見せる | **視聴者の悩みを一言で代弁して、結論を先に言う** |
| オチ | (笑)や余韻 | 行動喚起1つ＋次回予告 |

メルマガに一番近い型です。
「%name1%さん、ぱっちゃんです。」の代わりに、悩みの代弁から入ります。

**改行と空白行のリズムはそのまま。** 台本は読み上げるので、改行＝間になります。

## 大前提

- 教えすぎない。**1本で持ち帰らせるのは1つだけ。** 3つ話しても、最後に「今日やるなら1つ」に絞る
- きれいごとで終わらせない。**自分の失敗談と数字**が入っていない台本はボツ
- 上から教えない。「僕もやってました(笑)」の位置から話す

## 構成

```
【冒頭15秒】
視聴者の心の声を「」で代弁して、結論を先に言う。
「〜で止まってる。」→「今日の動画を最後まで見てくださいね。」
チャンネル名や挨拶から入らない。

【自己紹介】
3〜5行。何者で、どんな数字を持っているか。
そのあとすぐに自虐で落として距離を縮める。

【つかみのエピソード】
どん底の数字→転機→急上昇を短く。
ここで「この人の話は聞く価値がある」を作る。

ーーーーーー

【本題：3つのポイント】
先に3つを「・」で並べてから、1つずつ。
各ポイントの中身は必ずこの順番：

  1. 当時の僕がやっていたこと（ダメな例を具体的に）
  2. 「でも、」で転換
  3. なぜそれがダメなのか（理屈は短く）
  4. やり方を変えたらどうなったか（数字で）
  5. 今日からやることを「・」で3つ

ポイント同士は「ーーーーーー」で区切る。

【まとめ】
3つをもう一度「・」で並べる。
そのあと「今日、1つだけやるなら」で行動喚起を1つに絞り、理由をセットで言う。

【エンディング】
・チャンネルの方向性を3〜4行で
・チャンネル登録の呼びかけ（1回だけ）
・次回予告（引きを作る）
・コメント誘導（答えやすい質問を1つ）
```

## 尺の目安

| 動画の長さ | 文字数の目安 |
|---|---|
| 5分 | 1,500〜1,800字 |
| 8分 | 2,400〜2,800字 |
| 10分 | 3,000〜3,500字 |

トークは朗読より少し速いので、1分あたり300〜350字で見積もる。
ポイントは3つがちょうどいい。5つ以上は覚えてもらえない。

## この型でのNG

- 「〜が重要です」「〜を意識しましょう」だけで、数字も失敗談もない
- 3つのポイントを全部やらせようとする（行動喚起は1つ）
- 冒頭で自己紹介や挨拶を長々とやる
- 「絶対」「必ず稼げる」などの断定（YouTubeの規約的にも危ない）

## チェック

- [ ] 冒頭15秒で悩みの代弁と結論が入っているか
- [ ] 自分の失敗談が最低1つ、数字つきで入っているか
- [ ] 各ポイントに「当時の僕」→「でも、」→「変えたら」の流れがあるか
- [ ] 行動喚起が1つに絞れているか
- [ ] 次回予告とコメント誘導が入っているか
- [ ] 音読して、2〜4行＋空白行の間で息継ぎできるか
- [ ] 数字が本人の実績と一致しているか（AIが書いた数字は必ず差し替え確認）
