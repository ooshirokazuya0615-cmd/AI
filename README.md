# AI 発信基地

ぱっちゃん（EST）の発信物を、AIで「いつもの文体・いつもの型」で量産するためのリポジトリ。

原稿を書くツールを作る前に、まず **土台（文体データ・型・置き場所）** を固めるのがこのリポジトリの目的です。
土台が固いほど、あとで作るツールの精度がそのまま上がります。

## ディレクトリ

| 場所 | 何を置くか |
|---|---|
| `style/voice.md` | 文体プロファイル本体。改行のリズム、語り口、演出記号、NG集まで。**すべての生成物の基準** |
| `style/samples/` | 過去に自分で書いた原稿（お手本）。ここが厚いほどAIの再現度が上がる |
| `templates/` | コンテンツ種別ごとの「型」。メルマガ、ステップメール、LINE、セールスレター、ブログ、YouTube朗読 |
| `drafts/` | AIが生成した原稿の置き場所 |

## 使い方

Claude Code に指示するだけで動きます。

```
templates/melmaga.md の型で、「初心者が最初にやるべきこと」をテーマにメルマガを1通書いて
```

Claude は自動的に `style/voice.md` を読み、その文体で書きます。

スマホ（Claudeアプリ、または claude.ai/code）からも同じことができるので、
移動中にネタを投げておいて、あとで `drafts/` を確認する使い方ができます。

## 次のステップ

1. `style/samples/` に過去原稿を入れる ← **ここが最優先**
2. `templates/` の型を、実際に使いながら自分好みに育てる
3. 型が固まったら、専用ツール（LINEボット、原稿生成Webアプリなど）を作る
