# 過去原稿（お手本）の置き場所

**ここが、このリポジトリで一番大事なフォルダです。**

`style/voice.md` は「文体のルール」ですが、ルールだけでは本人らしさは出ません。
実際の原稿が積み上がるほど、AIの再現度は上がります。

## 何を入れるか

自分で書いた原稿なら何でも。優先順位はこの順です。

1. **反応が良かったメルマガ・LINE配信** — 一番効く
2. **ステップメール一式** — 全体の流れごと学習できるので価値が高い
3. **セールスレター** — 売る文章は型が違うので別枠で必要
4. **YouTube朗読シナリオ** — スカッと系・感動系それぞれ数本
5. ブログ記事、読者への呼びかけ文

## ファイル名の付け方

```
melmaga-2025-03-初心者が最初にやること.md
step-mail-01-出会い.md
sales-letter-2024-コンサル募集.md
youtube-sukatto-義母との一件.md
```

先頭に種別、次に日付かテーマ。後から探しやすければ細かいルールは気にしなくてOK。

## 中身の書き方

**改行と空白行を、配信したときのまま残してください。**
ここを整形してしまうと、この文体の一番の特徴（縦のリズム）が消えてしまいます。

コピペしてそのまま貼るのが正解です。加工しないでください。

## 注意

読者の個人情報（本名、メールアドレス、電話番号など）が入っている原稿は、
その部分を `〇〇さん` などに置き換えてから入れてください。
