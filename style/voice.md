# 文体プロファイル（EST／ぱっちゃん）

本人が書いたメルマガ原稿（約6万字・複数通のステップメール）から抽出した文体の癖。
代筆のゴールは、読者が「本人が書いた」と感じるレベルで再現すること。

## 最重要:視覚的リズム(改行と空白行)

この文体の最大の特徴は「縦のリズム」。文章の中身より先に、まずこの形を守ること。

- 1文を意味の切れ目で2〜4行に分割して改行する。1行はおおよそ15〜25文字。
- 意味のかたまり(2〜4行)ごとに空白行を1〜2行挟む。長い段落は絶対に作らない。
- 画面(特にスマホ)でスラスラ読める「呼吸するような余白」を意識する。

例(本人の原文):

```
僕はこれまで多くの方に出会い

多くの方に指導してきましたが、

このネット業界は自分が稼げればいい

という詐欺師同然のような人がいます。
```

※朗読シナリオの場合も、読み上げの「間」がこの改行位置に対応するよう、同じリズムで書く。

## 語り口と人称

- 一人称は「僕」。読者・視聴者への距離感は「親しい友達に話す丁寧語」。
- 文末は「〜ですね」「〜ですよ!」「〜してくださいね」「〜していきましょう!」「〜してみてください♪」など、柔らかく前向きに着地させる。
- 呼びかけは名前+さん(メルマガでは %name1%さん)。「あなた」より名前呼びを優先。
- 命令ではなく背中を押す言い方。「やれ」ではなく「サクッとやっていきましょう」「安心してついてきてくださいね!」。

## 話の転換のさせ方

短い接続句を「単独行」で置いてから話を切り替えるのが強い癖。

よく使う転換句: 「さて、」「さてさて、」「ですが、」「でも、」「とはいえ、」「なので、」「また、」「そして、」「もちろん、」「というわけで…」「それはつまり、」

例:

```
実績だけ見ると、なんか凄そうな人

に見えるかもしれません。

  

ですが、

  

「お金ではなく、個人で稼ぐスキル」

を追い求めていたら…
```

## 強調・演出の記号使い

- 重要なキーワードやコンセプトは『二重かぎ括弧』または【隅付き括弧】で囲む。例:『本物の稼げる情報を学んで欲しい』【即行動】
- 心の声・決意・キメ台詞は "ダブルクォート" や 「かぎ括弧」 で独立させて置く。
- 「間」を作る記号: 「・・・」「…」を単独行で置いて溜めてから落とす。「っと。」で独白を締める。
- 笑いは「(笑)」を文末に。ときどき「笑」だけ、砕けた場面では「ｗ」も可。
- 柔らかい呼びかけの文末にたまに「♪」。感嘆は「!」「!!」を惜しまない。
- 自虐やネタバレは(丸括弧の注釈)や「※」の補足で入れる。例:(それが僕のプロフィール画像のワンコというのはここだけの話です)

## 箇条書きのリズム

「・」で3〜4項目、それぞれ短くリズミカルに並べる。前後に空白行を置く。

```
・最も再現性が高く

・早く成果が出て

・失敗リスクが少ない
```

## 数字とディテールで具体化する

- 金額、月商・月収、年月、期間、人数などの具体的な数字をふんだんに入れて臨場感と説得力を出す。「たくさん稼いだ」ではなく「月商350万月収100万」。
- 生活のディテールも具体的に書く。「服はGUやユニクロ、車はシェアカー、通勤は自転車」のように固有名詞で描写する。

## ストーリーテリングの型(スカッと・感動シナリオにも直結)

本人のストーリーは常にこの流れで組む:

1. 平凡・どん底の日常を具体的に描く(謎の3時間残業、上司のつまらない武勇伝、給料は年1万円しか増えない)
2. 心の声をセリフで挿入して臨場感を出す(『ヤバイっすね!(笑)』「なんでこんなやつと一緒に飲んでるんだ。」)
3. 「ある日ふと気づいたんです。」のような転機の一文
4. 悟り・決意を「」で独立させてドンと置く
5. 出会い→挑戦→一度失敗→師や気づきを得て急上昇、というV字回復
6. 変化後の自由な生活を対比で描き、余韻やオチ((笑)や自虐)で締める

- 感情の頂点の直前には必ず「・・・」や空白行で溜めを作る。
- オチや意外な事実は最後まで引っ張ってから短く落とす。

## 独特の言葉選び・ノリ

- 造語や言葉遊びを恐れない: 「ウマウマ」「ぱっちゃんチルドレン」「稼げる漢(おとこ)」など。
- 「サクッと」「みるみる」「ワイワイ」「ギラギラ」「コツコツ」などのオノマトペを多用する。
- 「〜みたいな(笑)」で例え話を軽く締める。
- 大げさな表現のあとに、すぐ自虐で落とす: 「汗と涙の結晶ともいえる作品です」→ 数行後に自虐やツッコミを入れてバランスを取る。
- カジュアルな口語をそのまま書く: 「まっ、同じネットの仕事だしいっか。」「いっか」「なんか凄そうな人」。

## メルマガ特有の構成(メール・配信文を書く場合)

- 冒頭: 「%name1%さん、ぱっちゃんです。」の一行挨拶から入る。
- 本文をセクション分けする場合は「ーーーーーー」の罫線+見出しで区切る。
- 追伸は PS → PPS → PPPS と重ね、行動喚起・追加プレゼント・次回予告を置く。
- 締め: 「それでは、また明日の夜にメールしますね。」「最後までお読み頂きありがとうございました。」
- 読者への行動喚起は「インプット→アウトプット」「即行動」を軸に、理由(なぜそれが大事か)をセットで語る。

## やってはいけないこと

- 長い段落でぎっしり書くこと(この文体の対極)。
- 硬い書き言葉(「〜である」「〜と考えられる」「〜すべきだ」)。
- 上から目線の命令口調や、冷たい断定。
- 絵文字の多用(♪と!と(笑)が基本。絵文字はほぼ使わない)。
- 抽象的なきれいごとだけで数字やディテールがない文章。

## 書き終えたらチェック

1. スマホ画面を想定して、2〜4行+空白行のリズムになっているか
2. 転換句が単独行で置かれているか
3. 『』【】「・・・」(笑)などの演出記号が自然に散っているか
4. 具体的な数字・固有名詞・セリフが入っているか
5. 音読して「本人がしゃべっている」ように聞こえるか
