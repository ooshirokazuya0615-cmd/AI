# サムネ生成ツール

YouTube朗読サムネ（1280×720 PNG）を、JSONを書くだけで生成します。

```
node tools/thumbnail.mjs <spec.json> [出力先.png]
```

Claude Code に「スカッと系のサムネを3案作って」と言えば、
JSONの作成から生成まで全部やります。自分でJSONを書く必要はありません。

## 準備

Playwright（Chromium）が必要です。

```
npm install playwright
```

フォントは Google Fonts から**使う文字だけ**を自動で取ってきて、
`tools/.fontcache/` にキャッシュします。手動インストールは不要です。

## spec.json の書き方

```json
{
  "preset": "sukatto",
  "label": "スカッとする話",
  "lines": [
    "義母「同居しないなら",
    "[出て行け]」",
    "→ 私「[どうぞ]」"
  ],
  "sub": "家の名義、私でしたけど？"
}
```

| キー | 説明 |
|---|---|
| `preset` | `sukatto`（赤黒・極太ゴシック）か `kandou`（藍・明朝）|
| `label` | 左上（感動系は中央上）の小さいラベル。省略可 |
| `lines` | 大見出し。**`[ ]` で囲んだ部分がアクセント色**になる |
| `sub` | 一番下の小さい補足。省略可 |
| `bgImage` | 背景画像のパスかURL。省略可 |
| `bgOpacity` | 背景画像の濃さ（初期値 0.42）|
| `scale` | 文字サイズの微調整（1.0が基準。0.9で少し小さく）|
| `tracking` | 字間（初期値 `-.02em`）|
| `overrides` | プリセットの色などを個別に上書き（`accent`, `ink`, `stroke` など）|

**文字サイズは行数と一番長い行から自動で決まります。** 手で調整する必要は基本ありません。

## 効くサムネの作り方

- **1行は12文字以内。** 3行が上限。スマホでは320×180で表示されます
- **`[ ]` は1〜2箇所だけ。** 全部強調は、何も強調していないのと同じです
- **セリフを入れる。** 「」が入るだけでクリック率が変わります
- **`sub` にオチの手前まで書く。** 答えは書かない
- 作ったら**縮小して見る**こと。読めなければ文字が多すぎます

## 背景に画像を使う

イラストや写真は、このツールでは生成できません（AIで絵を描く機能がないため）。
別で用意した画像を `bgImage` に指定してください。

```json
{ "preset": "sukatto", "bgImage": "assets/kitchen.jpg", "bgOpacity": 0.5, "lines": ["..."] }
```

文字が読めなくなったら `bgOpacity` を下げてください。

## 新しいプリセットを足す

`tools/thumbnail.mjs` の `PRESETS` に追記します。
色（`ink` / `accent` / `stroke`）、背景、フォント、揃え方を指定するだけです。
