## 動かすときの注意

- `stickman/`・`otohame/`・`3d/` は `/home/user/AI/tools/nonverbal` を絶対パスで読み込みます。クローンの場所が違えば直してください。
- 追加で `pymunk`（stickman）と `Pillow`（voices）が要ります。
- `3d/` の Blender と pybullet は、Python 3.11 の別の仮想環境（約1.2GB）で動かしました。仮想環境はリポジトリに入れていません。`bpy==4.5.*` と `pybullet` を入れ直します。
- `asmr/` のバイノーラルは SADIE の HRIR（Google Resonance Audio に同梱の Subject_002、Apache-2.0）を使います。データは入れていないので、取り直して `asmr/dl/resonance/repo/third_party/SADIE_hrtf_database/...` に置きます（パスはスクリプトの `SAD`）。
- 測定結果の JSON（`*_report.json`、`measurements*.json` など）は、そのときの実測値です。
